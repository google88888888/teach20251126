第1套　计算机二级 WPS Office 高级应用　操作步骤详解
================================================

【写给零基础的你】
· 本套共三个科目：WPS文字（论文排版）、WPS表格（员工绩效）、WPS演示（光盘行动宣传）。
· 素材都在"考生文件夹"里：WPS.docx、ET.xlsx、WPP.pptx、绩效后台数据.txt、背景.png、光盘行动logo.png、锄地.png。
· 通用习惯：①每做完一大题按Ctrl+S保存；②文件从考生文件夹打开，不要改名、不要另存别处；③要求"输出为PDF"的，先保存原文件再输出。
· 名词解释：窗口顶部那排菜单（开始/插入/页面布局/引用……）叫"选项卡"，点开后下面那一条叫"功能区"，按钮都在功能区里。

------------------------------------------------
一、WPS文字：完善硕士毕业论文排版（11题）
------------------------------------------------

■第1题 设置文档属性摘要
要求：标题"工学硕士学位论文"、作者"张三"。
思路：文档属性是文件的"身份证"，考你能否找到属性入口。
步骤：
1. 点窗口左上角【文件】菜单。
2. 点【文档信息】（有的版本叫"属性"）。
3. 右侧属性面板："标题"框输入：工学硕士学位论文；"作者"框输入：张三。
4. 点面板外任意处关闭，Ctrl+S保存。

■第2题 页面设置
要求：上下边距2.5cm、左右3cm；页眉页脚距边界2cm；"只指定行网格"每页33行。
思路：边距和行数都在"页面设置"对话框里，行数藏在"文档网格"选项卡。
步骤：
1. 点【页面布局】选项卡。
2. 点【页边距】下拉箭头→最下面【自定义页边距…】。
3. "页边距"选项卡：上2.5、下2.5、左3、右3厘米；"距边界"页眉2、页脚2厘米。
4. 切到【文档网格】选项卡→选"只指定行网格"→"每页"输入33→确定。
提示："只指定行网格"只管每页行数；"指定行和字符网格"还限制每行字数，别勾错。

■第3题 修改样式
要求：正文中文字体宋体、西文Times New Roman；标题1/2/3中文黑体、西文Times New Roman；每章标题自动另起一页。
思路："样式"是格式的集合（字体+段落打包）。改样式=一次修改、全文生效。
步骤：
1. 【开始】→样式组右下角小箭头，右侧弹出"样式"窗格。
2. 找到"正文"→右键→【修改】。
3. 点左下角【格式】→【字体】：中文选"宋体"、西文选"Times New Roman"→确定。
4. 同样修改"标题1/2/3"：格式→字体→中文"黑体"、西文Times New Roman。
5. 章自动另起一页：右键"标题1"→修改→【格式】→【段落】→【换行和分页】选项卡→勾"段前分页"→确定。
提示：改的是样式本身（右键→修改），所有用了该样式的段落会一起变。

■第4题 修改多级编号
要求：章="第1章"、节="1.1"、条="1.1.1"；编号末尾无点号；编号后用空格与文字隔开；节在章后重新编号、条在节后重新编号（如第2章第1节是2.1）。
思路：多级编号要"链接到标题样式"才能跟标题走；"重新编号"保证第2章第1节从2.1开始。
步骤：
1. 光标点进任意章标题。
2. 【开始】→"多级编号"按钮（项目符号旁，图标1.1.1）→选最接近"第1章"的样式。
3. 再次【多级编号】下拉→【自定义…】，打开自定义对话框→点左下【更多】展开。
4. 级别1：编号格式为"第1章"（"第""章"是手输文字，灰底1是自动编号）；编号样式"1,2,3…"；"将级别链接到样式"选标题1；"编号之后"选"空格"。编号里若带"."删掉。
5. 级别2：格式"1.1"；链接标题2；编号之后"空格"；设置在级别1后重新编号。
6. 级别3：格式"1.1.1"；链接标题3；编号之后"空格"；在级别2后重新编号。
7. 确定→翻到第2章检查第1节是否为"2.1"。

■第5题 参考文献自动编号+正文交叉引用
要求：文献编号形如[1][2]，顶格左对齐（对齐位置0厘米）；第1章正文引注与文献建立交叉引用（字样不变），并设为上角标。
思路：手动打的[1]不会自动变号；改成自动编号后，正文用"交叉引用"抓取文献编号，以后增删文献按F9即可全部自动更新。
步骤：
A. 文献列表改自动编号：
1. 选中参考文献列表所有段落，删掉手动编号文字"[1]""[2]"（保留文献内容）。
2. 【开始】→"编号"下拉→【其他编号…】→编号选项卡→选一种1,2,3样式→【自定义】。
3. 编号样式选"1,2,3…"；在编号格式框里给自动编号前后补半角方括号变成"[1]"；"编号位置"选左对齐、对齐位置0厘米→确定。
B. 正文做交叉引用：
1. 到第1章正文，删掉原来手动标的"[1]"，光标停原处。
2. 【引用】选项卡→点【交叉引用】按钮。
3. "引用类型"选"编号项"；"引用内容"选"段落编号"；列表中点选对应文献→【插入】。
4. 选中刚插入的[1]→【开始】→点上标按钮"X²"（或Ctrl+Shift+加号）变成上角标。
5. 其余引注重复以上步骤。
提示：全部做完后可Ctrl+A全选→按F9刷新编号。

■第6题 图片题注
要求：第4章3张图片按章连续自动编号"图4-1"样式；"图"与编号间无空格；编号后一个半角空格接图名；图片与题注自动同页；正文交叉引用代替手动编号。
思路：题注=自动编号的图注，勾"包含章节编号"就自动带上章号；"与下段同页"保证图和图注不分家。
步骤：
1. 删除第4章3张图下方的手动编号（保留图名文字）。
2. 光标放在图名段落开头→【引用】→【题注】按钮。
3. 点【新建标签】→输入"图"→确定。
4. 点【编号】→勾选"包含章节编号"→"使用分隔符"选"-"（连字符）→确定。
5. 位置选"所选项目下方"→确定，生成"图 4-1"。把"图"和"4-1"之间的空格删掉（题目要求无空格），编号后留一个半角空格再接图名。
6. 3张图逐一插入题注，编号自动递增。
7. 图片与题注同页：【开始】→样式窗格→"图片"样式右键→修改→格式→段落→换行和分页→勾"与下段同页"→确定（图片在上、题注在下，图片"与下段同页"即可）。
8. 正文交叉引用：删掉正文手动写的"图4-1"→【引用】→【交叉引用】→引用类型"图"、引用内容"只有标签和编号"→选中对应图→插入。
提示：如果"图片"样式不存在，先选中一张图，在样式窗格"新建样式"命名为"图片"再改段落。

■第7题 三线表美化（表2-1）
要求：按内容调列宽并适应窗口；合并第一列相关单元格；上下边框1.5磅粗黑线、内部横框线0.5磅细黑线；标题行跨页自动重复。
思路：学术表格规范叫"三线表"：只有顶线、底线粗，栏目线细，无竖线。
步骤：
1. 点表格任意位置→顶部出现【表格工具】选项卡。
2. 表格工具→【自动调整】→先"根据内容调整表格"，再"根据窗口调整表格"（左右恰好充满版心）。
3. 合并：拖选第一列中需要合并的单元格→表格工具→【合并单元格】。
4. 边框：选中整个表格→右键→【边框和底纹】（或表格工具→边框下拉→边框和底纹）。
   · 先在"宽度"下拉选"1.5磅"→在右侧预览示意图上点"上框线""下框线"按钮（变粗）；
   · 再把宽度换成"0.5磅"→点"内部横框线"按钮→确定。
   顺序口诀：先选线型粗细，再点对应的线。
5. 标题行重复：光标放表格第一行任意单元格→表格工具→点【标题行重复】按钮（跨页时第一行自动出现在下页顶端）。

■第8题 添加目录
要求：封面后、正文前插入自动目录（1~3级）；格式刷把"参考文献"标题格式刷给"目录"标题；"目录"标题大纲级别设为"正文文本"；目录1级=黑体小四、2/3级=宋体小四、西文全部Times New Roman，且更新目录后格式不变。
思路：自动目录由标题样式生成；目录里的字体必须改"目录1/2/3"样式才能在更新后保持。
步骤：
1. 光标放封面最后→【插入】→【分隔符】→"下一页分节符"，产生目录页。
2. 光标放目录页→输入标题"目录"→回车另起一行。
3. 【引用】→【目录】下拉→选"自动目录1"（含1-3级）。
4. 格式刷：选中"参考文献"标题→【开始】→双击【格式刷】→刷"目录"两字→再点格式刷取消。
5. 选中"目录"标题→【开始】→段落组右下角箭头→"大纲级别"下拉→选"正文文本"（防止"目录"自己进目录）。
6. 目录字体：【引用】→【目录】下拉→【插入目录…】→点【修改】→分别选"目录1/目录2/目录3"→修改：
   目录1=黑体、小四；目录2、目录3=宋体、小四；三者的西文都设Times New Roman→一路确定。
提示：直接选中目录里的文字改字体是错误做法——更新目录会丢格式；必须改"目录样式"。

■第9题 分4节并独立编排页眉页脚
要求：封面/目录/正文章节/参考文献4节，每节从新页开始（全文不超8页）；封面无页眉横线，其余用"上粗下细双横线"；封面无页眉文字，目录和参考文献页眉="工学硕士学位论文"，正文章节页眉自动显示章标题（如"第1章 绪论"，半角空格分隔）且居中；封面无页码，目录=大写罗马数字，正文和参考文献=阿拉伯数字从1连续，页码在页脚居中。
思路：节是"页面格式的独立单元"。各节页眉页脚要先"断开与前一节的链接"（同前节）再分别设置；"自动显示章标题"靠"样式引用"（StyleRef域）实现。
步骤：
A. 分节：
1. 光标分别放在"封面末尾、目录末尾、参考文献标题前"→【页面布局】→【分隔符】→"下一页分节符"（共3个分节符，分出4节）。
2. 若出现多余空白页：显示编辑标记（开始→显示/隐藏编辑标记），删掉空段落。
B. 页眉：
1. 双击目录页页眉进入编辑→顶部出现【页眉和页脚】工具→确认取消"同前节/链接到前一节"按钮的高亮（每节都要断开）。
2. 封面节：页眉内容清空；选中页眉段落→【开始】→"边框"下拉→"无框线"（去掉默认横线）。
3. 其余节：【页眉横线】下拉→选"上粗下细双横线"样式。
4. 目录节、参考文献节：页眉输入"工学硕士学位论文"→段落居中。
5. 正文节：清空页眉文字→点【页眉和页脚】工具里的【样式引用】→选"标题1"→页眉自动显示当前章标题（如"第1章 绪论"）→居中。
   （若没有该按钮：【插入】→【文档部件】→【域】→类别"链接和引用"→StyleRef→样式名选"标题1"。）
C. 页码：
1. 双击页脚进入编辑，同样先断开各节"同前节"。
2. 封面节：页脚留空。
3. 目录节：【插入】→【页码】→样式选普通数字居中→【设置页码格式】→编号格式选"Ⅰ,Ⅱ,Ⅲ"→起始页码选Ⅰ→确定。
4. 正文节：插入页码（页脚、居中）→页码格式选"1,2,3"→起始页码1。参考文献节保持与正文连续（不断开即可，或在页面设置中设"续前节"）。
提示：目录页和正文页之间一定断开链接，否则罗马数字和阿拉伯数字会互相影响。

■第10题 公式样式制表位
要求："公式"样式实现公式内容在20字符处居中、公式编号在40.5字符处右对齐。
思路：制表位控制按Tab键后光标停的位置。公式段落=公式+Tab+编号，两个制表位分别管它们的位置。
步骤：
1. 【开始】→样式窗格→"公式"样式右键→【修改】→【格式】→【段落】→左下角【制表位】按钮。
2. 先点【全部清除】删掉旧制表位。
3. "制表位位置"输入20→对齐方式选"居中"→点【设置】。
4. 位置输入40.5→对齐选"右对齐"→【设置】→确定。
提示：段落里按第一个Tab到20字符处（输公式），再按Tab到40.5字符处（输编号）。

■第11题 输出带权限的PDF
要求：先保存WPS.docx；再"输出为PDF"，权限=禁止更改+禁止复制，权限密码123，不设打开密码。
步骤：
1. Ctrl+S保存文档。
2. 【文件】→【输出为PDF】。
3. 在对话框中点【权限设置】。
4. 勾选"禁止更改""禁止复制"；权限密码输入123、确认密码再输123；"打开密码"留空不填。
5. 确定→输出（输出位置默认就在考生文件夹=源文件目录）。
提示：这是WPS特色功能，MS Word没有对应按钮，考试机用WPS作答。

------------------------------------------------
二、WPS表格：员工绩效统计（12题）
------------------------------------------------
先打开ET.xlsx，左侧工作表标签：员工绩效汇总、Sheet3、统计等。

■第1题 按汉字宽度设置列宽
要求：工号4、姓名5、性别3、学历4、部门8、入职日期6、工龄4、绩效4、评价16、状态4（单位=汉字宽）。
思路：列宽单位就是"字符"（一个汉字宽）。一列一列设。
步骤：点A列列标选中整列→右键→【列宽】→输入4→确定；再依次B列5、C列3、D列4、E列8、F列6、G列4、H列4、I列16、J列4。

■第2题 统一日期格式
要求：F2:F201显示成2020-10-01（短横线分隔、月日两位）。
步骤：选中F2:F201→右键→【设置单元格格式】→"数字"选项卡→分类选"自定义"→类型框输入 yyyy-mm-dd →确定。
提示：yyyy=4位年，mm=2位月，dd=2位日。

■第3题 条件格式标重复姓名
要求：B2:B201重复值显示"浅红填充色深红色文本"。
步骤：选中B2:B201→【开始】→【条件格式】→【突出显示单元格规则】→【重复值】→保持默认"浅红填充色深红色文本"→确定。

■第4题 状态列下拉列表
要求：J2:J201下拉含"确认/待确认"，输错时停止并提示"输入内容不规范，请通过下拉列表选择"。
步骤：
1. 选中J2:J201→【数据】→【数据有效性】（有的版本叫"数据验证"）。
2. "设置"页：允许选"序列"；来源框输入：确认,待确认 （注意用英文半角逗号）。
3. 切"出错警告"页：样式选"停止"；标题随意（如：输入内容不规范）；错误信息输入：输入内容不规范，请通过下拉列表选择。
4. 确定。点J2应出现下拉箭头。

■第5题 插入批注
要求：G1加批注"工龄计算，满一年才加1。例如:2018-11-22入职，到2020-10-01，工龄为1年。"
步骤：右键点G1→【插入批注】→粘贴/输入题目给的内容→点表外任意单元格结束。

■第6题 DATEDIF算工龄
要求：G2:G201空白单元格用公式算"截至目前"工龄，每满一年加1，且是动态时间。
思路：DATEDIF(起始日,结束日,"y")算整年数；TODAY()=打开文件当天，天天变，满足"动态"。
步骤：G2输入 =DATEDIF(F2,TODAY(),"y") →回车→鼠标放G2右下角小黑点（填充柄）双击，自动填到G201。
提示：千万别写成 =DATEDIF(F2,"2020-10-1","y")，写死日期就不是动态了。

■第7题 导入txt并用VLOOKUP取数
要求：把"绩效后台数据.txt"全部内容粘贴到Sheet3的A1，分列到A-E列（级别列设为文本）；再用查找引用函数按工号把"本期绩效""本期绩效评价"填入汇总表H、I列。
思路：记事本数据挤在一列时用"分列"拆开；跨表取数用VLOOKUP（垂直查找）。
步骤：
1. 用记事本打开"绩效后台数据.txt"→Ctrl+A全选→Ctrl+C。
2. 切到ET的Sheet3→点A1→Ctrl+V粘贴。
3. 若数据全挤在A列：选中A列→【数据】→【分列】→选"分隔符号"→下一步→勾选实际分隔符（制表符/逗号/空格，看预览效果）→下一步→第3步先选中"级别"那一列→右上"列数据格式"选"文本"→完成。数据应按 工号/姓名/级别/本期绩效/本期绩效评价 分布在A-E列。
4. 回"员工绩效汇总"表：H2输入 =VLOOKUP($A2,Sheet3!$A:$E,4,0) →回车→双击填充柄填到H201（第4列=本期绩效）。
5. I2输入 =VLOOKUP($A2,Sheet3!$A:$E,5,0) →填充到I201（第5列=本期绩效评价）。
提示：$A2表示锁住A列（横向复制不跑偏），最后的0=精确匹配。

■第10题 COUNTIFS多条件计数
要求：B2统计研发中心博士后人数，再把B2公式复制到B2:G4，统计三个部门不同学历人数（注意引用方式）。
思路：行方向要换部门、列方向要换学历→公式里部门用$A2（锁列不锁行）、学历用B$1（锁行不锁列），这样一拖就全对。假设统计表A2:A4是部门名、B1:G1是学历名。
步骤：
1. 统计表B2输入：=COUNTIFS(员工绩效汇总!$E:$E,$A2,员工绩效汇总!$D:$D,B$1)
   （汇总表E列=部门、D列=学历）
2. 回车后拖B2填充柄到G2→再选中B2:G2拖到第4行。
3. 验证B2结果=研发中心博士后人数。
