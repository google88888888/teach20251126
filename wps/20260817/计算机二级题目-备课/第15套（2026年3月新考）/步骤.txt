【通用操作习惯说明】
◆ "选项卡"指软件窗口顶部的一排文字按钮（如：开始、插入、页面布局、引用、视图）；
  点某个选项卡后，下方会出现一条功能区，功能区按"分组"（组名写在功能区底部小字）排列按钮。
◆ "下拉按钮"指按钮右侧带一个小倒三角形"▽"的按钮，点它会弹出列表。
◆ 选中图片/表格/图形后，功能区会多出一个上下文选项卡（如"图片工具""表格工具""文本工具"
  "绘图工具"），本步骤都会明确指出。
◆ 每道大题做完后记得按 Ctrl+S 保存。

第1题  在首页插入图片并编辑
──────────────────────────────────────────
■ 第(1)问：插入封面背景图，铺满A4页面并衬于文字下方

步骤1：把光标点到文档第1页（首页）开头位置。
步骤2：点顶部【插入】选项卡 → 在"图片"分组里点【图片】按钮右侧的
       下拉小三角 ▽ → 在弹出的列表中点【本地图片】，打开"插入图片"对话框。
步骤3：在对话框左侧逐级点开文件夹，找到 考生文件夹\WPS文字\ 文件夹，
       选中里面的"W封面背景图.tif" → 点右下角【打开】按钮。图片即插入首页。
步骤4：单击选中这张图片 → 顶部出现【图片工具】选项卡，点开它 → 在
       "大小和位置"分组中：把"高度"框改成 29.7 厘米，"宽度"框改成 21 厘米。
       （提示：如果改高度时宽度会自动跟着变，说明纵横比被锁定。解决办法：点
        "大小和位置"分组右下角的小箭头图标打开"布局"对话框 → 在"大小"选项卡
        中取消勾选"锁定纵横比" → 再分别输入高29.7、宽21 → 确定。）
步骤5：仍在【图片工具】选项卡 → 点"排列"分组中的【环绕】下拉按钮 ▽ →
       在列表中选择【衬于文字下方】。
步骤6：仍在【图片工具】选项卡 → 点【对齐】下拉按钮 ▽ → 在列表中先点
       【水平居中】，再点一次【对齐】下拉按钮 ▽ → 点【垂直居中】。
       （这样图片就会相对于页面水平、垂直都居中，正好铺满A4封面。）

■ 第(2)问：在文档末行插入出版LOGO并美化

步骤1：把光标点到首页的最后一行（书名文字下方的空行）。
步骤2：点【插入】选项卡 → "图片"分组 → 【图片】下拉按钮 ▽ → 【本地图片】。
步骤3：找到 考生文件夹\WPS文字\ 文件夹，选中"W出版LOGO.jpg" → 点【打开】。
步骤4：单击选中图片 → 【图片工具】选项卡 → "大小和位置"分组中设置：
       高度 = 2.4 厘米、宽度 = 8 厘米（同样如遇锁定纵横比，用布局对话框取消锁定）。
步骤5：选中图片所在的段落（把光标放在图片旁边那一行即可） → 点【开始】
       选项卡 → "段落"分组中点【居中对齐】按钮（快捷键 Ctrl+E），让图片水平居中。
步骤6：保持图片被选中 → 【图片工具】选项卡 → 点【抠除背景】下拉按钮 ▽ →
       选【设置透明色】 → 此时鼠标变成一支带笔的小箭头，用它在图片的"黑色"
       区域上单击一下，黑色立即变透明。
步骤7：仍在【图片工具】选项卡 → 点【颜色】下拉按钮 ▽ → 在列表中选择
       【黑白】选项（在"颜色模式"类下）。图片颜色即变为黑白。

第2题  在首页插入横向文本框并编辑
──────────────────────────────────────────
■ 第(1)问：把书名移入文本框并做艺术字效果

步骤1：光标定位在首页 → 点【插入】选项卡 → "文本框"分组 → 点【文本框】
       下拉按钮 ▽ → 选择【横向】命令 → 此时鼠标变成十字，在首页中部按住
       鼠标左键拖动画出一个矩形，松开后即生成一个横向文本框。
步骤2：选中文档第一行文字"行业企业安全生产风险管理与隐患治理"，按
       Ctrl+X 剪切 → 再把光标点进刚才画的文本框内，按 Ctrl+V 粘贴。
步骤3：选中文本框内的所有文字 → 顶部出现【文本工具】选项卡 → 在"字体"
       分组中依次设置：字体 = 黑体；字号框中直接输入 36（磅）；再点【加粗】
       按钮（B 字样按钮，快捷键 Ctrl+B）。
步骤4：仍在【文本工具】选项卡 → 找到"文本效果格式"分组 → 点【快速样式】
       下拉按钮 ▽ → 在样式列表中选择"填充 - 矢车菊蓝，着色1，阴影"
       （第4行第1个样式，鼠标悬停会显示名称）。

■ 第(2)问：双行合一（方括号样式）

步骤1：在文本框内选中"行业企业安全生产"这8个字（注意：不含"风险管理与
       隐患治理"）。
步骤2：点【开始】选项卡 → "段落"分组 → 点【中文版式】下拉按钮 ▽（两个
       字符重叠的小图标） → 选【双行合一】，弹出"双行合一"对话框。
步骤3：在对话框中勾选【带括号】复选框 → 在"括号样式"下拉框中选择方括号
       样式 [ ] → 点【确定】。

■ 第(3)问：文本框尺寸与无轮廓

步骤1：单击选中文本框（点文本框边框） → 顶部出现【绘图工具】选项卡 →
       在"大小和位置"分组中设置：高度 = 3 厘米、宽度 = 16 厘米。
步骤2：仍在【绘图工具】选项卡 → "设置形状格式"分组 → 点【轮廓】下拉按钮
       ▽ → 选择【更多设置】，右侧弹出"属性"窗格。
步骤3：在"属性"窗格中点【形状选项】选项卡（小五边形图标） → 点【线条】
       分类 → 选择【无线条】单选按钮。文本框轮廓即消失。
       （完成后可点窗格右上角 × 关闭"属性"窗格。）

■ 第(4)问：精确定位文本框（水平20%、垂直25%）

步骤1：保持文本框被选中 → 【绘图工具】选项卡 → 点"大小和位置"分组右下角
       的小箭头【其他】按钮，打开"布局"对话框。
步骤2：切换到【位置】选项卡 → 在"水平"区域选中【相对位置】单选按钮，
       在数值框输入 20%，后面的"相对于"下拉框选择【页面】。
步骤3：在"垂直"区域同样选中【相对位置】单选按钮，数值框输入 25%，
       "相对于"下拉框选择【页面】 → 点【确定】。

第3题  文档文本样式设置（修改4个样式）
──────────────────────────────────────────
■ 修改"标题1"样式

步骤1：把光标点到任意一个章标题段落中（如"第1章 安全生产风险管理"）。
步骤2：点【开始】选项卡 → "样式和格式"分组 → 在"快速样式"库中找到
       【标题1】样式 → 在它上面单击鼠标右键 → 选【修改样式】，打开
       "修改样式"对话框。
步骤3：在对话框中间"格式"分组里：先把"类别"下拉框选为【所有脚本】
       （这样中文字体才生效） → "字体"选【黑体】 → "字号"选【二号】 →
       点【加粗】按钮（B）。
步骤4：点对话框左下角【格式】下拉按钮 ▽ → 选【段落】，打开"段落"对话框：
       对齐方式 = 居中对齐；段前 = 0.5 行；段后 = 0.5 行；
       行距 = 1.5倍行距 → 点【确定】回到"修改样式"对话框 → 再点【确定】。

■ 修改"标题2"样式（同样方法）

步骤1：光标放到任意节标题段落（如"第1节 安全生产风险的概念和分类"）。
步骤2：【开始】→"快速样式"库中右键【标题2】→【修改样式】。
步骤3：类别 = 所有脚本；字体 = 黑体；字号 = 三号；点【加粗】。
步骤4：【格式】→【段落】：居中对齐、段前段后各 0.5 行、1.5倍行距 →
       确定 → 确定。

■ 修改"标题3"样式

步骤1：光标放到"一、安全生产风险的概念"这类三级标题段落上。
步骤2：右键"快速样式"库中的【标题3】→【修改样式】。
步骤3：类别 = 所有脚本；字体 = 黑体；字号 = 四号；点【加粗】。
步骤4：【格式】→【段落】：对齐 = 两端对齐；首行缩进 = 2字符；
       段前 = 0行；段后 = 0行；行距 = 1.5倍行距 → 确定 → 确定。

■ 修改"自定义正文"样式

步骤1：光标放到正文段落中（套用了"自定义正文"样式的段落）。
步骤2：右键"快速样式"库中的【自定义正文】→【修改样式】。
步骤3：点【格式】下拉按钮 ▽ → 选【字体】：中文字体 = 宋体；
       字形 = 常规；字号 = 小四 → 确定。
步骤4：再点【格式】下拉按钮 ▽ → 选【段落】：对齐 = 两端对齐；
       首行缩进 = 2字符；段前 = 0行；段后 = 0行；行距 = 固定值，
       设置值 = 22磅 → 确定 → 确定。

第4题  表格"表1-5"编辑设置
──────────────────────────────────────────
步骤1：在文档中找到"表1-5 风险等级取值区间表"字样（第1章第3节，
       搜Ctrl+F输入"表1-5"可快速定位），其下方就是目标表格。
步骤2：把鼠标移到表格第一行的左侧，鼠标变成斜向箭头时单击，选中表格
       第一行（内容为"重大风险 | 55<D≤100"那一行）。
步骤3：顶部出现【表格工具】选项卡 → "插入单元格"分组 → 点【在上方插入行】
       按钮，表格上方出现一个空行。
步骤4：选中这个新插入的行 → 【表格工具】→"表格属性"分组中：行高输入
       0.8 厘米 → 再点同一分组的【标题行重复】按钮（让它呈选中状态）。
步骤5：光标点进新行第1个单元格，输入"风险等级"；再点进新行第2个单元格，
       输入"取值区间"。
步骤6：选中第一行（刚输入的两个标题） → 【表格工具】→"字体"分组 → 点
       【加粗】按钮（B）。
步骤7：把鼠标移到表格左上角出现十字标记 时单击，选中整个表格 →
       【表格样式】→ 点"快速样式"库右下角的【下拉按钮】▽ 展开样式列表 →
       在"中色系"分类中选择【中度样式2 - 强调1】。

第5题  插入并编辑智能图形
──────────────────────────────────────────
步骤1：找到第2章第3节中"如图2.2所示"下方的段落，把光标定位在
       "通报、通知、整改、反馈、验收"这段文字的后面。
步骤2：点【插入】选项卡 → "插图"分组 → 点【智能图形】按钮，打开
       "选取智能图形"对话框 → 选中【基本流程】（"流程"分类下第一个） →
       点【确定】。
步骤3：刚插入的图形只有3个方框，不够放5个词：选中最后一个（最右边）
       方框 → 顶部【设计】选项卡（智能图形工具） → 点【添加项目】下拉
       按钮 ▽ → 点【在后面添加项目】；再重复操作一次，共点两次，使图形
       达到5个方框。
步骤4：回到原文，选中"通报"两个字按 Ctrl+X 剪切 → 点第1个方框内部 →
       Ctrl+V 粘贴。用同样方法依次把"通知""整改""反馈""验收"分别
       剪切粘贴到第2、3、4、5个方框中（原文那行字剪完后只剩顿号，把
       剩余的顿号删除，空段落也删掉）。
步骤5：单击选中整个智能图形 → 【设计】选项卡右侧"大小和位置"分组中
       设置：高度 = 3 厘米、宽度 = 12 厘米。
步骤6：把光标点在智能图形所在的段落 → 【开始】选项卡 →"段落"分组 →
       点【居中对齐】按钮，使图形在页面居中。

第6题  新建自定义多级编号列表
──────────────────────────────────────────
步骤1：把光标放到"第1章 安全生产风险管理"标题文字中。
步骤2：点【开始】选项卡 → "段落"分组 → 点【编号】下拉按钮 ▽（1,2,3
       字样按钮旁的小三角） → 在列表下方点【自动编号】命令，打开
       "项目符号和编号"对话框。
步骤3：切换到【多级编号】选项卡 → 选中类似"第一章、第一章第一节…"
       样式的编号框 → 点右下角【自定义】按钮，打开"自定义多级编号列表"
       对话框。
步骤4：在左上角"级别"列表中选中【1】：
       ● 在中间"编号格式"框中，确保文字是"第 X 章"（X 是带灰色底纹的
         自动编号；如果不是，把框内清空，输入文字"第"，再从"编号样式"
         中选"1,2,3..."让灰色编号出现在中间，再输入"章"）；
       ● "编号样式"选【1,2,3...】；
       ● "将级别链接到样式"下拉框选【标题1】；
       ● "编号之后"下拉框选【空格】。
步骤5：在"级别"列表中选中【2】：
       ● "编号格式"框中做成"第 X 节"（清空原有内容，输入"第"，中间
         保留灰色自动编号（编号样式选"1,2,3..."），再输入"节"；
         注意：不要包含级别1的编号，"前一级别编号"选【无】）；
       ● "编号样式"选【1,2,3...】；
       ● "将级别链接到样式"选【标题2】；
       ● "编号之后"选【空格】 → 点【确定】。
步骤6：此时每个标题前出现自动编号，但原标题文字里还有手写编号，需要
       手动删除：逐个选中标题中的"第1章""第2章"和"第1节"~"第4节"
       等手动编号文字及后面多余空格，按 Delete 删除（全文共10处：
       2处章编号 + 8处节编号），让标题只显示自动编号。

第7题  图形题注添加与交叉引用
──────────────────────────────────────────
■ 第(1)问：给第1章第3节的图形插入题注

步骤1：找到第1章第3节"第3节 安全生产风险管理过程"下的那幅流程图，
       把光标点在图形正下方、图注文字"安全生产风险管理过程"这一行的
       开头（即：图形下方、文字之前）。
步骤2：点【引用】选项卡 → "题注"分组 → 点【题注】按钮，打开"题注"对话框。
步骤3：在"题注"对话框中："标签"下拉框选【图】。
步骤4：点【编号】按钮，打开"题注编号"对话框：
       ● "编号格式"选【1,2,3...】；
       ● 勾选【包含章节编号】复选框；
       ● "章节起始样式"下拉框选【标题1】；
       ● "使用分隔符"下拉框选【.（句点）】；
       → 点【确定】 → 回到"题注"对话框再点【确定】。
       此时图形下方出现"图 1.1"字样的题注。

■ 第(2)问：修改"题注"样式

步骤1：点【开始】选项卡 → "样式和格式"分组 → 在"快速样式"库中找到
       【题注】样式 → 右键它 → 选【修改样式】。
步骤2：在"修改样式"对话框中："样式基于"下拉框选择【图注】。
步骤3：点【格式】下拉按钮 ▽ → 选【字体】：中文字体 = 宋体；
       字号 = 小四 → 点【确定】 → 再点【确定】。

■ 第(3)问：交叉引用

步骤1：找到该图形上方段落中"…四个环节，如 所示。"这句话，把光标点到

──────────────────────────────────────────
（第25张幻灯片上有5个对象：正中间1个大组合+左侧、右侧、下方3个组合）

■ 第(1)问：正中间组合对象：出现+向左弧线+陀螺旋

步骤1：在左侧选中第25张幻灯片 → 单击选中正中间的组合对象。
步骤2：点【动画】选项卡 → 点"动画"分组中的【动画】下拉按钮 ▽（或展开
       动画库） → 在"进入"分类中选择【出现】动画。
步骤3：点【动画】选项卡 →"高级动画"分组 → 点【自定义动画】按钮，打开
       "自定义动画"窗格 → 点【添加效果】按钮 → 选【动作路径】→ 在展开
       的列表中选【向左弧线】 → 然后点窗格中该路径动画条目右侧的下拉
       按钮 ▽ → 选【反转路径方向】。
步骤4：再点【添加效果】按钮 → 选【强调】分类中的【陀螺旋】。
步骤5：在"自定义动画"窗格的动画列表中设置"开始"方式：
       ● 选中"出现"动画 → "开始"下拉框选【单击时】；
       ● 选中"向左弧线"动画 → "开始"选【之后】；
       ● 选中"陀螺旋"动画 → "开始"选【之后】。

■ 第(2)问：左、右、下三个组合：飞入

步骤1：单击选中左侧的组合对象 → 【动画】选项卡 → 动画库 → "进入"
       分类选【飞入】 → 在"自定义动画"窗格中："方向"选【自左侧】；
       "开始"选【单击时】；"速度"选【快速】。
步骤2：选中右侧的组合对象 → 同样添加【飞入】 → 方向 =【自右侧】；
       开始 =【单击时】；速度 =【快速】。
步骤3：选中下方的组合对象 → 添加【飞入】 → 方向 =【自底部】；
       开始 =【单击时】；速度 =【快速】。

第7题  第2张幻灯片目录超链接
──────────────────────────────────────────
（第2张目录页有3个目录项："背景情况""修改目的""主要修订内容"，
  分别链接到第3、7、12张幻灯片。操作方法相同，以第一项为例：）

步骤1：选中第2张幻灯片 → 选中文字"背景情况"。
步骤2：点【插入】选项卡 →"链接"分组 → 点【超链接】按钮，打开"插入
       超链接"对话框。
步骤3：在对话框左侧"链接到"列表中选【本文档中的位置】→ 在中间"请选择
       文档中的位置"列表中选择【3. 幻灯片 3】。
步骤4：点对话框右下角的【超链接颜色】按钮，打开"超链接颜色"对话框：
       ● 点"超链接颜色"下拉按钮 ▽ → 选【黑色，文本1】；
       ● 选中【链接无下划线】按钮；
       ● 点【应用到全部】 → 点【确定】。
步骤5：回到"插入超链接"对话框 → 点【确定】。
步骤6：用同样方法：选中"修改目的" → 超链接到【7. 幻灯片 7】；
       选中"主要修订内容" → 超链接到【12. 幻灯片 12】（后两项的
       "超链接颜色"设置会自动沿用，无需重复设置；若需设置，同步骤4）。

第8题  第24张幻灯片表格编辑
──────────────────────────────────────────
■ 第(1)问：插入标题行、合并单元格、行高1.8厘米

步骤1：选中第24张幻灯片 → 单击表格 → 选中表格的第1行（鼠标移到第1行
       左侧，箭头变黑色斜箭头时单击）。
步骤2：顶部【表格工具】选项卡 →"行列"分组 → 点【在上方插入行】按钮。
步骤3：选中新插入的第1行 → 点【表格工具】选项卡 →"合并"分组 → 点
       【合并单元格】按钮。
步骤4：保持选中该行 → 在"单元格大小"分组（或"行高"框）中设置行高 =
       1.8 厘米。

■ 第(2)问：输入标题并设置格式

步骤1：光标点进第1行，输入：改革经营权管理制度
步骤2：选中第1行文字 → 【表格工具】选项卡 →"字体"分组：字号选/输入
       22 磅；"对齐方式"分组中点【垂直居中】，再点【文本居中】（水平
       居中）→ 让文字位于单元格正中。
步骤3：保证该行无项目符号：选中该行文字 → 点【开始】选项卡 →"段落"
       分组 → 点【项目符号】下拉按钮 ▽ → 选【无】（若原本就没有项目
       符号可跳过）。

■ 第(3)问：套用表格样式

步骤1：把鼠标移到表格左上角十字标记 处单击，选中整个表格。
步骤2：点【表格样式】选项卡 → 点"快速样式"库右下角【下拉按钮】▽ →
       在"浅色系"分类中选择【浅色样式2 - 强调1】。

第9题  输出PDF格式"讲义"
──────────────────────────────────────────
■ 第(1)问：每页横向显示4张幻灯片

步骤1：点左上角【文件】选项卡 → 选【输出为PDF】，打开"输出为PDF"
       对话框。
步骤2：先选中列表中的 WPP.pptx → 点对话框中的【高级设置】按钮，打开
       "高级设置"对话框。
步骤3：在"输出内容"中选中【讲义】单选按钮 → "每页幻灯片数量"设为 4 →
       "顺序"选中【水平】 → 点【确认】按钮。

■ 第(2)问：保存到源文件目录

步骤1：回到"输出为PDF"对话框 → "保存目录"选择【源文件目录】
       （即 考生文件夹\WPS演示）→ 文件名保持 WPP 不变。
步骤2：点【开始输出】按钮 → 输出完成后关闭对话框。
步骤3：按 Ctrl+S 保存 WPP.pptx 演示文稿，然后关闭。
        WPS演示题全部完成！

附：易错点提醒（考试前再过一遍）
════════════════════════════════════════════════════════════════
1. WPS文字第1题：封面图尺寸是"高29.7×宽21"（A4纵向），别写反；
   背景图和LOGO必须用"考生文件夹\WPS文字"里的素材文件。
2. WPS文字第2题：文本框位置是"相对页面"的水平20%、垂直25%，
   别选成"相对页边距"。
3. WPS文字第6题：多级编号做完必须手动删除文中10处旧编号，否则
   编号会出现两次。
4. WPS文字第8题：正文页码样式是"-1-"（带短横线），不是普通"1,2,3"；
   前言是罗马数字"I,II,III"；两处都要设"起始页码1+应用范围本节"；
   正文页眉要先取消"同前节"再删除原有内容。
5. WPS表格第2题：高级筛选的条件区域是 I2:L5（含"日期/日期/省份/类别"
   标题行），不要多选、少选。
6. WPS表格第4题：分类汇总要做两次（先省份、后类别），第二次一定要
   取消勾选"替换当前分类汇总"！
7. WPS表格第7题：公式 MATCH(B15,...) 拖动填充到 H16 后检查各列结果。
8. WPS表格第8题：页脚"第X页/共Y页"必须用"页码"和"总页数"两个按钮
   插入代码，不能手打数字。
9. WPS演示第1题：所有设置都在"幻灯片母版"视图里做，做完记得点
   "关闭母版视图"。
10. WPS演示第5题：先给5张设"分割"，再给其余设"淡出"（或反之），
    两批互不覆盖即可。
11. 三道大题的"输出为PDF"都要选"源文件目录"，文件名保持不变。
12. 随时 Ctrl+S 保存，尤其是每道大题做完后。
