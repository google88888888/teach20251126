第3套　计算机二级 WPS Office 高级应用　操作步骤详解
================================================
【概况】三科：WPS文字（王林毕业论文排版）、WPS表格（诺德公司工资计算分析）、WPS演示（电子商务行业PPT，素材在SC.docx中）。参考文件：封面样式参考、页眉参考、员工福利.png等。习惯：做完一题Ctrl+S。

------------------------------------------------
一、WPS文字：毕业论文排版（8题）
------------------------------------------------

■第1题 打开素材
步骤：从考生文件夹打开WPS.docx（双击打开即可，后续都在这个文件里操作）。

■第2题 页面设置+封面
要求：A4纸；上下左右边距分别为3.5、2.5、2.8、2.8厘米；装订线在左侧0.3厘米；页脚距边界1.5厘米；参考"封面样式参考"图片插入封面页。
思路：装订线是留给装订的额外空白，位置和宽度单独设置；封面插在最前面。
步骤：
1. 【页面布局】→右下角箭头打开"页面设置"→页边距：上3.5、下2.5、左2.8、右2.8；装订线位置选"左"、装订线宽0.3；页脚1.5→确定。
2. 打开考生文件夹"封面样式参考"图片照着做：光标放全文最前→【插入】→【空白页】→在新页上输入封面内容（校名"中国信息科技大学"、论文标题、姓名学号等），排版尽量与参考图一致（可用居中、加大字号）。

■第3题 分节
要求：封面、目录、摘要、结论、致谢、参考文献、附录1以及四个正文章节各自独立成节，且每节从新的一页开始。
思路：在每个部分开头前插"下一页分节符"；也可以在标题样式中勾"段前分页"，但独立节必须用分节符。
步骤：依次把光标放到"目录""摘要""第1章""结论""致谢""参考文献""附录1"等每个部分标题的最前面→【页面布局】→【分隔符】→"下一页分节符"。

■第4题 样式设置（核心大题）
要求：①所有"正文"样式首行缩进2字符；②红色标题套"标题1"并改样式：微软雅黑、三号、加粗、黑色、居中、段前段后0.5行、特殊格式"无"；③蓝色标题套"标题2"：宋体+Times New Roman、小四、加粗、黑色、段前段后0.5行、无特殊格式；④绿色标题套"标题3"：宋体、五号、黑色、段前0.5行、无特殊格式；⑤手动编号全部替换为自动多级编号。
思路：先给标题"穿上样式"，再改样式格式；红色是章、蓝色是节、绿色是条。
步骤：
1. 【开始】→样式窗格→"正文"右键→修改→格式→段落→特殊格式选"首行缩进"、磅值2字符→确定。
2. 逐个选中红色标题（摘要、第一章…）→点样式窗格"标题1"。全部套完后：右键"标题1"→修改→字体：中文微软雅黑、三号、加粗、颜色黑色；段落：居中、段前段后0.5行、特殊格式"无"。
3. 蓝色标题全部套"标题2"→修改样式：中文宋体、西文Times New Roman、小四、加粗、黑色；段前段后0.5行、无特殊格式。
4. 绿色标题全部套"标题3"→修改样式：宋体、五号、黑色、段前0.5行、无特殊格式。
5. 自动编号：光标放任一章标题→【开始】→多级编号→选与原文一致的样式（一、/（一）/1. 或 第一章/1.1/1.1.1）→【自定义】→级别1链接标题1、级别2链接标题2、级别3链接标题3→确定→再删除各标题上残留的手动编号文字。
提示：套样式后标题前的手动编号字样（如"第一章"）必须删掉，只留标题文字，让自动编号来编。

■第5题 页眉页脚
要求：①封面不显示页眉；正文章节偶数页页眉"中国信息科技大学毕业论文"+左侧LOGO、奇数页页眉显示当前章节名+右侧LOGO；其他节页眉显示当前章节名（参考"页眉参考"文档）；②封面不显示页码；页脚正中插页码：目录和摘要=Ⅰ、Ⅱ、Ⅲ，正文其他部分="第1页"样式。
思路：奇偶页不同是关键开关；LOGO图在页眉里用"插入图片"；章节名用"样式引用"（StyleRef域）。
步骤：
1. 【页面布局】→页面设置→"版式"选项卡→勾"奇偶页不同"→应用于"整篇文档"。
2. 双击正文节偶数页页眉→先取消"同前节"→输入"中国信息科技大学毕业论文"→【页眉和页脚】工具→【图片】→插入LOGO→放在文字左侧。
3. 奇数页页眉：清空→【样式引用】→选"标题1"（自动显示章节名）→【图片】插LOGO放右侧。（无该按钮则【插入】→【文档部件】→域→StyleRef→标题1）
4. 其他节（摘要、目录等）：页眉用"样式引用"显示该节名称。
5. 封面节：页眉页脚清空（断开同前节后删除内容）。
6. 页码：封面节无页码；目录/摘要节页脚→【插入】→【页码】→页面底端居中→【设置页码格式】→"Ⅰ,Ⅱ,Ⅲ"、起始Ⅰ；正文节→页码格式选样式"第1页"（中文样式），起始页码1→各节都断开同前节再设置。

■第6题 删空行+横向分栏
要求：删除文档中所有空行；"附录1"小节纸张方向横向；附录1内容分等宽两栏并加分割线。
步骤：
1. 删空行：Ctrl+H→查找 ^p^p →替换为 ^p →全部替换（多点几次直到提示0处）。
2. 光标放附录1节内→【页面布局】→纸张方向→横向（应用于本节）。
3. 选中附录1正文→【页面布局】→【分栏】→【更多分栏】→选"两栏"→勾"栏宽相等""分隔线"→应用于"所选文字"→确定。

■第7题 图片+题注
要求：把图片1、图片2插入合适位置；所有图片应用基于"正文"新建的"图片"样式（居中、无特殊格式、0.9倍行距）；7个图标题编号按顺序替换为题注；修改"题注"样式：居中、无特殊格式、行距固定值20磅。
步骤：
1. 找到文中两处缺少图的位置（正文提到配图处）→光标放下一行→【插入】→【图片】→选图片1.jpg/图片2.jpg。
2. 【开始】→样式窗格→【新建样式】→名称"图片"、样式类型"段落"、样式基于"正文"→格式→段落：居中、特殊格式"无"、行距"0.9倍"→确定→选中每张图应用"图片"样式。
3. 题注：删掉图标题里的手动编号→光标放图题开头→【引用】→【题注】→新建标签"图"→确定（编号1,2,3…顺序自动）。
4. "题注"样式右键→修改→段落：居中、特殊格式无、行距"固定值20磅"→确定。

■第8题 目录+图目录+水印
要求：在"目录"文字后插入目录（替换占位文字），显示3级、不使用超链接；"图目录"文字后插入图目录；目录节插入宋体、倾斜文字水印"目录"、透明度80%；输出PDF"毕业论文.pdf"。
步骤：
1. 删掉"请在此插入目录"占位文字，光标留原处→【引用】→【目录】→【插入目录…】→显示级别3→取消勾选"使用超链接"→确定。
2. 删掉"请在此插入图目录"→【引用】→【插入表目录/图目录】→题注标签选"图"→确定。
3. 水印：光标放目录节→【页面布局】→【水印】下拉→【自定义水印…】→选"文字水印"→文字"目录"、字体"宋体"、版式"倾斜"、透明度80%→应用于"本节"（先在该节中操作）→确定。
4. Ctrl+S→【文件】→【输出为PDF】→输出位置考生文件夹、文件名：毕业论文 →输出。

二、WPS表格：员工工资计算与统计（6大题）
------------------------------------------------
素材：员工资料表 + 1月~12月共12张月表 + 工资数据分析表。

■第1题工作组批量操作（最重要技巧！）
要求：①用VLOOKUP完善12张表的"性别""合同种类"；②12张表套"表样式浅色1"且"转换成表格并套用样式"；③A:R列宽8字符、全表居中、数字格式"数值2位小数"；④算"应发合计"（基本+岗位+工龄+补贴+医疗+奖金-考勤扣款）；⑤按分段税率算"个人所得税"；⑥算"应扣合计"（四险+个税）。
思路：12张表结构一样→用"工作组"一次搞定全部：点"1月"标签→按住Shift点"12月"标签（全选成组，标题栏显示[工作组]）→在一张表上操作=12张同时改→做完点任一标签取消成组。
步骤：
1. 成组后：性别列（如C2）输入 =VLOOKUP($A2,员工资料!$A:$F,3,0) ；合同种类列输入 =VLOOKUP($A2,员工资料!$A:$F,6,0) （列号按员工资料实际布局调整）→向下填充。
2. 选中数据区域→【开始】→【表格样式（套用表格格式）】→"表样式浅色1"→弹窗选"转换成表格，并套用表格样式"→确定（勾"表包含标题"）。
3. 选中A:R列→右键列宽8→【开始】→居中按钮；选中数字区域→右键→设置单元格格式→数值、2位小数。
4. 应发合计列（如M2）：=D2+E2+F2+G2+H2+I2-J2 （按实际列顺序：基本+岗位+工龄+补贴+医疗+奖金-考勤）。
5. 个税（超额分段：≤2000部分0；2000~4000部分3%；4000~8000部分8%；>8000部分10%）。设应扣税工资x=应发合计-住房公积金-养老保险-医疗保险-失业保险，公式（假设应发在M、各保险在N:Q）：
   R2 =MAX(0,MIN(S2,4000)-2000)*3% + MAX(0,MIN(S2,8000)-4000)*8% + MAX(0,S2-8000)*10%
   其中 S2 =M2-N2-O2-P2-Q2（可先把S列算成"应扣税工资"辅助列，再算税）。
   理解：MIN(S2,4000)-2000=落在2000~4000段的钱（不够2000取0）；同理4000~8000段；超出8000部分=MAX(0,S2-8000)。
6. 应扣合计：=N2+O2+P2+Q2+R2（四险+个税）。
提示：公式里的列字母要打开文件后对照实际表头调整，思路不变。

■第2题 5月表组合图表
要求：用5月表"姓名、奖金、应发合计"做图表：姓名横坐标；奖金=次坐标"带数据标记的折线图"；应发合计=主坐标"簇状柱形图"；应用样式；主纵坐标数字0位小数；次纵坐标最大600最小200；应发合计加数据标签、系列填充"巧克力黄，着色6，深色25%"；图表无标题无网格线；插入到B19:N33区域。
步骤：
1. 5月表选中姓名、奖金、应发合计三列数据→【插入】→【组合图】? （若没有组合图入口：插入簇状柱形图→再改系列类型）
2. 设置：应发合计→簇状柱形图、主坐标轴；奖金→带数据标记的折线图、勾"次坐标轴"。
3. 双击主纵坐标轴→数字→小数位数0。双击次坐标轴→最大值600、最小值200。
4. 点图表→"+"→取消"图表标题"、取消"网格线"；勾"数据标签"（选应发合计系列添加）。
5. 右键应发合计柱子→"设置数据系列格式"→填充→主题颜色"巧克力黄，着色6，深色25%"。
6. 应用一种图表样式：【图表工具】→样式库任选。
7. 移动：拖动图表左上角对准B19→拖右下角控制点到N33。

■第3题 9月表排行与统计
要求：①按姓名升序排序；②S1输入"实发排行榜"，S列公式生成"第1名、第2名…"；③用COUNTIFS完成C26:C29（性别×合同种类计数）。
步骤：
1. 点数据区任一格→【数据】→【排序】→主要关键字"姓名"、升序→确定。
2. S1输入：实发排行榜 →S2输入：="第"&RANK(R2,$R$2:$R$17,0)&"名" →双击填充（R列=实发合计列，按实际改）。
3. C26（按表中标签位置）：=COUNTIFS($C$2:$C$17,"男",$F$2:$F$17,"合同工") 类似形式，行列条件对照C25:B29的标签写4个公式。

■第4题 工资数据分析3个透视表
要求：①A6起透视表：16个员工全年各项福利总和（参考"员工福利.png"）；②H6起：5个指定员工上半年工资平均值（参考"上半年数据统计.png"）；③L6起：合同工和劳务工全年应发/应扣/实发平均值（参考"不同合同平均值.png"）；④值数字格式"数值2位+千位分隔符"。
思路：多张月表数据要汇总→透视表数据源允许选多区域时用"多重合并"；简单情况下新建辅助表把各月数据复制堆叠，再对辅助表做透视。
步骤：
1. 若软件支持多表区域透视：点【插入】→【数据透视表】→数据源逐个添加各月工作表区域（WPS支持按Ctrl多选区域/自定义多区域）；否则新建一张"汇总"辅助表，把1-6月或12个月的数据行复制粘贴堆在一起。
2. 透视表①：行=工号/姓名，值=各项福利（补贴、医疗补助等）求和。
3. 透视表②：筛选或行=工号(A002,A004,A006,A008,A0010)，值=各工资项"平均值"。
4. 透视表③：行=合同种类，值=应发合计、应扣合计、实发合计（平均值）。
5. 值格式：右键值→值字段设置→数字格式→数值、2位、千位分隔符。
6. 位置：创建时选"现有工作表"→分别点A6/H6/L6；布局对照参考图片微调。

■第5题 保护员工资料表
要求：保护"员工资料"工作表，密码为空。
步骤：点到"员工资料"表→【审阅】→【保护工作表】→密码留空→确定。

------------------------------------------------
三、WPS演示：电子商务PPT（12题）
------------------------------------------------

■第1题 模板与页脚
要求：每张幻灯片页脚插入"前瞻产业研究院"；应用"plan.potx"模板。
步骤：
1. 【插入】→【页眉页脚】→勾"页脚"→输入：前瞻产业研究院 →全部应用。
2. 【设计】→主题/模板下拉→【浏览主题/导入模板】→选考生文件夹plan.potx→应用。

■第2题 第1页标题与动画
要求：版式"标题幻灯片"；主标题"中国电子商务行业发展现状及趋势分析"=隶书32磅、艺术字预设"填充-黑色，文本1，轮廓-背景1，清晰阴影-着色5"；副标题"前瞻产业研究院"=黑体20磅、颜色"海洋绿，着色2，深色25%"；主标题动画"进入-十字形扩展"方向"外"速度"快速"；副标题"进入-飞入""自左下部"、开始"之后"。
步骤：
1. 输入主副标题文字→【开始】→版式确认"标题幻灯片"。
2. 选中主标题→字体"隶书"、32磅→【文本工具】→艺术字样式→按名字选"填充-黑色，文本1，轮廓-背景1，清晰阴影-着色5"。
3. 副标题→"黑体"、20磅、字体颜色主题色"海洋绿，着色2，深色25%"。
4. 主标题→【动画】→"十字形扩展"→效果选项"外"→速度"快速"。
5. 副标题→动画"飞入"→效果选项"自左下部"→开始"上一动画之后"。

■第3题 第3页图片与文本
要求：版式"两栏内容"；标题"电子商务概述"；tupian2.jpg插入右侧，高6.5cm宽10.2cm，水平位置19.5cm相对"左上角"、垂直位置-2cm相对"居中"；轮廓4.5磅"海洋绿，着色2，深色25%"；图片动画"强调-陀螺旋""逆时针""半旋转"开始"之后"延迟1秒；SC.docx相应文本插入左侧，文本动画"进入-棋盘"方向"下"速度"快速"；顺序先文本后图片。
步骤：
1. 改版式、输标题。
2. 右侧插入tupian2.jpg→右键"大小和位置"：高6.5、宽10.2；位置：水平19.5cm（相对于左上角）、垂直-2cm（相对于居中）。
3. 【图片工具】→图片轮廓→粗细4.5磅→颜色"海洋绿，着色2，深色25%"。
4. 打开SC.docx复制相应段落→粘贴到左侧内容区。
5. 图片→动画"陀螺旋"→效果选项"逆时针、半旋转"→开始"上一动画之后"→延迟1秒。
6. 文本→动画"棋盘"→方向"下"→速度"快速"。
7. 【动画窗格】里把文本动画拖到图片前面（先文本后图片）。

■第4题 第4页智能图形
要求：版式"仅标题"、标题"我国电子商务行业发展历程"；插入智能图形（效果见题目图，一般是流程/时间线类）。

■第5题 第5页表格+组合图表
