【写在前面的话】
这台电脑上的绝大部分设置，都集中在两个地方：
  ① "设置"（新式设置，微软主推）—— 快捷键 Win + I
  ② "控制面板"（老式设置，功能更全）—— 搜索"控制面板"即可打开
本指南会告诉你：每一项设置是干什么的、具体在哪里、怎么改。
【小白提示】"Win键"就是键盘左下角印着 Windows 田字格图标的那一个键。

───────────────────────────────────────────────────────────────
第一部分：怎样打开"设置"和"控制面板"
───────────────────────────────────────────────────────────────

一、打开"设置"的 5 种方法（任选其一，方法2最快）
  方法 1（最常用）：
    ① 按一下键盘上的 Win 键，打开"开始菜单"
    ② 在开始菜单里找到齿轮形状的"设置"图标，点击即可
       （Win10 在左侧一列小图标里；Win11 在开始菜单底部固定区域）
  方法 2（最快，强烈建议记住）：
    同时按住 Win 键和字母 I 键（Win + I），设置窗口立即弹出
  方法 3：右键点击屏幕左下角的开始按钮（Windows 徽标）
    → 在弹出的菜单中点"设置"（小技巧：按 Win + X 也能弹出此菜单）
  方法 4：点击任务栏（屏幕底部那一条）上的搜索框/搜索图标
    → 输入"设置"两个字 → 点"打开"
  方法 5：点击屏幕右下角的通知区域（时间日期那一角）
    → Win11：点铃铛图标 → 再点右上角齿轮图标
    → Win10：弹出侧边栏后，点"所有设置"

二、打开"控制面板"的 3 种方法
  方法 1：按 Win 键 → 直接输入"控制面板" → 回车或点"打开"
  方法 2：按 Win + R 弹出"运行"小窗口 → 输入 control → 回车
  方法 3：Win11 也可在设置里搜：设置 → 右上角搜索框 → 输入"控制面板"
  【说明】Win11 把很多功能搬进了"设置"，但控制面板仍然保留，
  一些经典设置（最典型的是"鼠标指针样式"）只能在控制面板里改。

───────────────────────────────────────────────────────────────
第二部分："设置"里能改什么（11 大板块详解）
───────────────────────────────────────────────────────────────
先按 Win + I 打开"设置"。左侧是一列大分类，点进每个分类后，
右侧会出现具体项目。下面按顺序逐个板块讲解。

【板块 1】系统
进入路径：设置 → 系统

  1. 屏幕（显示设置）——管"看得见"的一切
     路径：设置 → 系统 → 屏幕（Win10 叫"显示"）
     ▶ 亮度和颜色：拖动滑块调节屏幕亮度；可开"夜间模式"
       （晚上屏幕变暖黄色护眼，可设定定时自动开启）
       【提示】显示器本身下边框/背面的实体按键，也能调亮度对比度
     ▶ 缩放：把文字和图标整体放大/缩小（推荐 100% 或 125%），
       觉得字太小/太大的朋友改这里
     ▶ 分辨率：屏幕清晰度。一般选带"（推荐）"字样的最高值。
       分辨率不对时字体会发虚、图标异常变大
     ▶ 方向：横屏/竖屏切换
     ▶ 多显示器设置：检测、识别、复制/扩展/仅第二屏幕
     ▶ HDR：高动态范围（需显示器支持）
     快捷进入法：在桌面空白处点鼠标右键 → 点"显示设置"
     【提示】想要更精细的显示参数（色彩、刷新率、游戏画质），
     还可以右键桌面 → "NVIDIA 控制面板"/"AMD Radeon 设置"/
     "英特尔显卡控制中心"（装了什么显卡就有什么）

  2. 声音——管"听得见"的一切
     路径：设置 → 系统 → 声音
     ▶ 输出设备：选择声音从哪里出来（扬声器/耳机/HDMI显示器）
     ▶ 音量：总音量滑块
     ▶ 输入设备：选择麦克风（视频通话时对方听你说话用）
     ▶ 音量混合器：单独控制每个软件的音量
       （快捷打开：右键点任务栏右下角小喇叭图标 → 音量混合器）
     ▶ 更多声音设置：可改系统提示音方案、通信时自动减音量等

  3. 通知
     路径：设置 → 系统 → 通知
     ▶ 通知总开关：不想被任何弹窗打扰就关掉它
     ▶ 逐个软件开关：可以只关某个烦人的软件的通知
     ▶ 勿扰模式（Win10 叫"专注助手"）：可设定时间段自动屏蔽通知

  4. 电源和电池——管"用电"和"睡眠"
     路径：设置 → 系统 → 电源和电池（台式机叫"电源"）
     ▶ 电源模式：最佳能效 / 平衡 / 最佳性能
     ▶ 屏幕和睡眠：设置"几分钟不动电脑后关闭屏幕/进入睡眠"
       ——笔记本耗电快、或怕离开时被人偷看，重点设置这里
     ▶ 电池使用情况、节电模式（笔记本专用）

  5. 存储——管"硬盘空间"
     路径：设置 → 系统 → 存储
     ▶ 查看各个盘的剩余空间
     ▶ 存储感知：开启后 Windows 自动清理临时文件和回收站
     ▶ 清理建议：一键清理不需要的文件，释放空间

  6. 多任务
     ▶ 窗口贴靠：拖窗口到屏幕边缘自动分屏排列的开关和方式

  7. 就近共享：与附近电脑互传文件的开关（类似手机"隔空投送"）

  8. 关于——查看电脑基本信息 ★常用
     路径：设置 → 系统 → 关于
     ▶ 能看到：CPU 型号、内存大小、系统版本、电脑名字
     ▶ 重命名这台电脑：改名后需重启才生效

  9. 激活：查看 Windows 是否已激活
  10. 疑难解答：系统出问题时的一键自动修复工具
  11. 恢复：重置此电脑（恢复出厂）、高级启动
      ⚠ 慎用！重置会清空已装软件（可选"保留我的文件"保住个人文件）
  12. 投影：允许手机/其他电脑投屏到本机
  13. 远程桌面：允许别人远程控制你的电脑（默认关闭，谨慎打开）
  14. 剪贴板：开启"剪贴板历史记录"后，按 Win+V 可查看复制历史


【板块 2】蓝牙和其他设备
进入路径：设置 → 蓝牙和其他设备（Win10 叫"设备"）

  1. 蓝牙开关与添加设备
     ▶ 顶部有蓝牙总开关
     ▶ 点"+ 添加设备"可以配对：蓝牙耳机、鼠标、键盘、手机等
     操作流程：先把耳机/鼠标调成"配对模式"（一般长按功能键，
     指示灯快速闪烁），再点"添加设备"→ 选"蓝牙"→ 列表中点它
  2. 设备列表：查看已连接鼠标键盘的电量、删除（取消配对）设备
  3. 打印机和扫描仪
     ▶ 添加设备会自动搜索，多数打印机可自动安装驱动
     ▶ 搜索不到时点"手动添加"，按提示装驱动
  4. 鼠标、触摸板：详见本指南"第三部分 鼠标专题"
  5. 笔（触控笔）：快捷菜单、手感设置（触屏/平板设备用）
  6. 自动播放：插入 U 盘/光盘时弹不弹提示窗口
  7. USB：USB 设备异常时的提醒设置

【板块 3】网络和 Internet——上网相关都在这
进入路径：设置 → 网络和 Internet
（快捷进入：右键点任务栏右下角的网络图标 → "网络和 Internet 设置"）

  1. WLAN（Wi-Fi 无线上网）
     ▶ 打开/关闭 Wi-Fi 总开关
     ▶ 连接 Wi-Fi 的步骤：
       ① 点任务栏右下角的 Wi-Fi 图标（像声波扇形）
       ② 在弹出的列表里点你要连的网络名
       ③ 勾选"自动连接"→ 点"连接"按钮
       ④ 输入密码（输入时屏幕不显示字符是正常的）→ 下一步
     ▶ 忘记网络：路由器密码改了连不上时用——点该网络 →
       "忘记"，然后重新连一次，输入新密码
     ▶ 查看密码：已连上的网络 → 网络属性 → 往下找"查看密码"
  2. 以太网（插网线上网）：查看网线连接状态、IP 地址等
  3. 移动热点：把电脑变成一个 Wi-Fi 路由器，给手机共享网络
  4. 飞行模式：一键关闭所有无线设备（Wi-Fi、蓝牙）
  5. VPN：连接公司虚拟专用网络（需要公司提供服务器地址和账号）
  6. 代理：一般保持"自动检测设置"开、其余全关。
     ⚠ 突然上不了网时，先来检查这里有没有被勾选了代理！
  7. 高级网络设置
     ▶ 查看网络适配器：看网卡是否被"禁用"（禁用了就右键启用）
     ▶ IP 分配：手动改 IP 地址（一般保持"自动 DHCP"不动）
     ▶ 网络重置：网络彻底乱了用它，重置后需重启电脑

【板块 4】个性化——把电脑变成"你的样子"
进入路径：设置 → 个性化
（快捷进入：在桌面空白处点右键 → "个性化"）

  1. 背景（桌面壁纸）
     ▶ 可选：图片 / 纯色 / 幻灯片（定时自动换一叠壁纸）
     ▶ 点"浏览照片"可以选自己拍的照片当壁纸
  2. 颜色：主题色、深色/浅色模式（夜间推荐深色）、透明效果
  3. 主题：一键更换整套外观（壁纸+配色+声音），可下载新主题
  4. 锁屏界面
     ▶ 更换锁屏壁纸；选择锁屏上显示的状态（天气等）
     ▶ 屏幕保护程序：在此页点"屏幕保护程序"老入口
       ——几分钟不动电脑后出现的动态画面，可设恢复时需输密码
  5. 字体：查看已装字体；把网上下载的字体文件拖进来即可安装
  6. 开始菜单（Win11）：哪些文件夹显示在开始菜单、推荐项目开关
  7. 任务栏 ★常用
     ▶ 任务栏对齐方式：居中（Win11 默认）或靠左（像 Win10）
     ▶ 自动隐藏任务栏：勾选后任务栏平时藏起来，
       鼠标移到屏幕底部才出现
     ▶ 选择哪些系统图标显示：搜索、任务视图、小组件、天气等
     ▶ 其他系统托盘图标：控制哪些软件的小图标显示在右下角
  8. 设备使用情况：影响推荐内容，可不管

【板块 5】应用——软件管理
进入路径：设置 → 应用

  1. 安装的应用（Win10 叫"应用和功能"）
     ▶ 卸载软件：找到软件名 → 点右侧"…" → 卸载
       （这里还能看每个软件占了多少硬盘空间）
     ▶ 高级选项：修复、重置某个出问题的软件
  2. 默认应用——设置"双击文件时用哪个软件打开" ★常用
     ▶ 设置默认浏览器（比如把 Edge 换成 Chrome）：
       点开你想设为默认的浏览器 → 点"设为默认值"
     ▶ 按文件类型设置：比如 .pdf 用什么打开、.mp4 用什么播放
     ▶ 按链接类型设置：点网页链接、邮件链接用什么打开
  3. 启动（开机自启动管理）★重要
     ▶ 电脑开机慢、开机后卡？来这里关掉不需要开机就运行的软件
     ▶ 操作：把不需要的项目右边开关拨到"关"
     （另一入口：Ctrl+Shift+Esc 打开任务管理器 → "启动应用"）
  4. 高级应用设置：应用别名、离线地图、网页应用等

【板块 6】账户——管"你是谁"
进入路径：设置 → 账户

  1. 您的信息：改头像、改账户显示名称
  2. 登录选项 ★重要
     ▶ 密码：微软账户密码（忘了可去微软官网 account.live.com 找回）
     ▶ PIN（推荐新手用）：4~6 位数字，开机只输数字，方便；
       设置路径：登录选项 → PIN(Windows Hello) → 添加
     ▶ 图片密码：用照片上画的手势解锁
     ▶ Windows Hello 人脸/指纹：需摄像头/指纹硬件支持
     ▶ 动态锁：配对手机的蓝牙一断开就自动锁屏
  3. 家庭和其他用户
     ▶ 添加账户：给别人在这台电脑上开一个独立账户（互不干扰）
     ▶ 更改账户类型：标准用户 / 管理员
  4. Windows 备份：把设置同步到云端、OneDrive 备份桌面文件夹


【板块 7】时间和语言
进入路径：设置 → 时间和语言

  1. 日期和时间
     ▶ 自动设置时间：一般保持开启
     ▶ 时区：显示的时间不对先查这里（中国应为"(UTC+08:00) 北京"）
     ▶ 手动设置：自动不准时，先关掉"自动设置时间"，
       再点"更改"按钮手动输入
     ▶ 附加时钟：可在时钟处再显示第二个时区的时间
  2. 语言和区域
     ▶ 添加语言：如添加"英语(美国)"用于打游戏/软件兼容
     ▶ Windows 显示语言：把整个系统界面换成另一种语言
  3. 输入（输入法相关）
     ▶ 高级键盘设置：切换输入法的快捷键、语言栏开关
     ▶ 触摸键盘设置、表情符号面板 (Win + . ) 相关设置
  4. 区域：日期/时间显示格式（如 2026/8/25 还是 2026-8-25）

【板块 8】游戏
  1. Xbox Game Bar：按 Win+G 呼出的游戏工具条的总开关
  2. 捕获：录屏/截图设置（录制画质、是否录声音）
     截图快捷键：Win + Alt + PrtScn；录屏：Win + Alt + R
  3. 游戏模式：玩游戏时让系统优先分配性能

【板块 9】辅助功能（无障碍）——字太小、看不清、操作不便都来这
进入路径：设置 → 辅助功能

  视觉类：
  1. 文本大小：整体放大系统文字（老年朋友福音），改完立即生效
  2. 视觉效果：动画开关、透明度、滚动条粗细
  3. 鼠标指针和触控 ★
     ▶ 指针大小（1~15 格滑块）、指针颜色（白/黑/反色/自定义彩色）
  4. 对比度主题：高对比度配色，让字和背景反差更大
  5. 讲述人：屏幕朗读软件，把屏幕上的文字读出来
     （开关快捷键：Win + Ctrl + Enter）
  6. 放大镜：屏幕放大工具（Win + 加号 放大，Win + Esc 退出）
  7. 颜色滤镜：色盲/色弱模式（也可开"灰度"变黑白屏）
  听觉类：
  8. 音频：单声道（左右耳机放同一声音）、视觉警报（用闪光提醒）
  交互类：
  9. 语音：语音输入（按 Win + H 直接说话打字）
  10. 键盘：粘滞键、筛选键、大写锁定提示音、屏幕键盘开关
  11. 鼠标：用键盘数字小键盘控制鼠标（鼠标坏了的应急办法）

【板块 10】隐私和安全性
进入路径：设置 → 隐私和安全性

  1. Windows 安全中心（微软自带杀毒）★重要
     ▶ 病毒和威胁防护：快速扫描、全盘扫描、勒索软件保护
     ▶ 防火墙和网络保护：一般保持全部开启
     ▶ 应用和浏览器控制：SmartScreen 拦截危险程序
     ▶ 设备安全性：内核隔离（内存完整性）
  2. 查找我的设备：丢了电脑可以定位（需登录微软账户）
  3. 开发者选项：普通用户不要动
  4. 权限（位置、相机、麦克风、通知、账户信息……）
     ▶ 逐项控制哪些软件允许用摄像头/麦克风/定位
     ▶ 摄像头/麦克风总开关：不想被任何软件用到就整体关掉

【板块 11】Windows 更新（Win10 叫"更新和安全"）
进入路径：设置 → Windows 更新

  1. 检查更新：手动点一下，安装最新补丁（建议每月点一次）
  2. 暂停更新：最多可暂停几周
  3. 更新历史记录：看装过哪些更新；更新后出问题可在这里卸载
  4. 高级选项
     ▶ 接收其他 Microsoft 产品的更新
     ▶ 活跃时间：设定你常用电脑的时段，避免它自动重启打扰你
     ▶ 传递优化：限制更新下载占用网速
  （Win10 此板块还包含：备份、恢复、激活、疑难解答等入口）

───────────────────────────────────────────────────────────────
第三部分：鼠标设置专题（指针样式、速度、滚轮、触摸板）
───────────────────────────────────────────────────────────────
鼠标能设置的东西最多，分两个入口：新式"设置"和控制面板老入口。
（★改"指针样式"在控制面板里，直接看本部分第二节★）

一、新式入口：设置 → 蓝牙和其他设备 → 鼠标
  打开步骤：按 Win + I → 左侧点"蓝牙和其他设备"→ 往下拉，
  在"相关设置"区点"鼠标"
  能设置的项目：
  1. 鼠标主按钮：默认"左"。左撇子可改成"右"（左右键功能互换）
  2. 鼠标指针速度：滑块直接调快慢（较新版本 Win11 才有此项）
  3. 一次滚动的行数：默认 3，嫌滚轮慢可调大（如 6）
  4. 提高指针精确度：开关（相当于老入口的"增强指针精度"）
  5. 触摸板（笔记本）：
     ▶ 灵敏度：最敏感 / 高 / 中 / 低（防止手碰触摸板乱跳）
     ▶ 轻触点击、双指滚动缩放开关
     ▶ 三指/四指手势：如三指上滑看所有窗口、三指下滑回桌面、
       三指向左右切换窗口，四指点一下开操作中心等

二、经典入口 ★改鼠标指针样式的核心位置★：控制面板 → 鼠标
  打开步骤（3 种方法任选）：
  方法 1：按 Win 键 → 输入"鼠标" → 点"更改鼠标指针的外观"
  方法 2：按 Win + R → 输入 main.cpl → 回车
  方法 3：打开控制面板 → "硬件和声音" → "鼠标"

  弹出的"鼠标 属性"窗口有几个标签页，逐个讲解：

  【标签 1】鼠标键
  ▶ 切换主要和次要的按钮：勾选后左右键互换（左撇子用）
  ▶ 双击速度：拖滑块调整；右边有个文件夹图标可测试——
    能双击打开/关上文件夹说明速度合适
  ▶ 单击锁定：勾选后按住一会儿即可松手，拖拽东西不用一直按着

  【标签 2】指针 ★想换鼠标箭头样式看这里★
  ▶ "方案"下拉框：整套现成的指针样式，例如：
    · Windows 标准（普通大小）
    · Windows 标准（大）/ Windows 标准（特大）——看不清指针就选特大
    · Windows 黑色（大/特大）——白底背景上更醒目
    · Windows 反色、Windows 忙碌时的各种变化……
    选好后点"应用"，指针立即变化
  ▶ 自定义列表：可单独替换某一种状态的指针（如"正常选择"的
    小箭头、"后台忙碌"的小圈圈）：
    选中某一项 → 点"浏览"→ 在文件列表里选 .cur 或 .ani 文件
    → 点"打开" → 最后点"应用"
    （从网上下载的指针主题包，解压会得到一堆 .cur/.ani 文件，
     用上面的方法逐个替换；如果包里有 .inf 文件，
     右键它选"安装"可一键整套安装）
  ▶ 使用默认值：改乱了点它一键还原成系统原装指针

  【标签 3】指针选项
  ▶ 移动：★鼠标太快/太慢在这里调★
    拖动"选择指针移动速度"滑块，越靠右鼠标跑得越远
  ▶ 对齐：勾选"自动将指针移动到对话框中的默认按钮"
    ——弹出窗口时指针自动跑到"确定"按钮上，省得找
  ▶ 可见性：
    · 显示指针轨迹：指针会拖出一条尾巴（一般不开）
    · 在打字时隐藏指针：建议勾选
    · 在按 CTRL 键时显示指针的位置：★强烈建议勾选★
      鼠标找不到了就按 Ctrl，屏幕上会出现一圈波纹提示位置

  【标签 4】滑轮（有的系统显示为"轮"）
  ▶ 垂直滚动：滚轮滚一格，页面向下走几"行"（默认 3）
  ▶ 水平滚动：按住 Shift 滚滚轮可横向滚动，这里设一格滚几字符

  【标签 5】硬件
  ▶ 查看鼠标名称和驱动状态；点"属性"→"驱动程序"选项卡，
    可以更新驱动或回滚驱动（鼠标漂移、不灵时试试）

三、补充说明
  1. 指针的"大小/颜色"还有一个新入口：
     设置 → 辅助功能 → 鼠标指针和触控（可选彩色指针）
  2. 罗技、雷蛇等品牌鼠标有自家驱动软件（如 Logitech G HUB），
     DPI、灯效、按键宏在自家软件里设置，不在系统设置里

第四部分：键盘与输入法设置专题
───────────────────────────────────────────────────────────────

一、输入法（打字软件）设置
  路径：设置 → 时间和语言 → 语言和区域
  1. 添加/删除输入法：
     "中文(简体，中国)"右边三个点 → 语言选项 → 往下拉到
     "键盘"区 → "添加键盘"（如微软拼音、英语等）
  2. 切换输入法：按 Win + 空格（或 Ctrl + Shift）
  3. 中英文切换：直接按一下 Shift（微软拼音默认）
  4. 微软拼音详细设置：语言选项里点"微软拼音"→"语言选项"，
     可以改：默认中/英文、候选词个数、模糊拼音、自定义短语、
     按键方式（如改用 Ctrl+空格 切换中英文）等
  5. 输入法图标不见了：
     设置 → 时间和语言 → 输入 → 高级键盘设置 →
     勾选"使用桌面语言栏（如果可用）"

二、键盘本身的设置
  1. 按键重复速度（按住一个键连发的快慢）：
     按 Win + R → 输入 control keyboard → 回车
     ▶ "字符重复"区：重复延迟（按住多久开始重复）、
       重复率（每秒重复几次），下方空白框可按住字母测试
     ▶ 光标闪烁速度：同一窗口上方的滑块
  2. 粘滞键/筛选键等特殊按键方式：
     设置 → 辅助功能 → 键盘
     ▶ 粘滞键：按 Ctrl、C、V 这类组合键可以一个一个按
     ▶ 筛选键：忽略短暂重复的按键（手抖总按出两个字时用）
     ▶ 按键提示音、大写锁定声音提醒
  3. 屏幕键盘（键盘坏了的应急办法）：
     设置 → 辅助功能 → 键盘 → 打开"屏幕键盘"开关；
     或按 Win + Ctrl + O 直接呼出

三、笔记本功能键行为（F1~F12）
  部分笔记本默认 F1~F12 是亮度/音量快捷键，想直接当 F 键用，
  需进 BIOS 把 "Hotkey Mode / Action Keys Mode" 关闭
  （怎么进 BIOS 见第七部分），或按 Fn+Esc 锁定 Fn（视机型而定）

───────────────────────────────────────────────────────────────
第五部分：控制面板经典设置详解
───────────────────────────────────────────────────────────────
打开方法见第一部分。控制面板按类别分为 8 大块：

1. 系统和安全
   ▶ Windows Defender 防火墙：开/关防火墙、单独放行某软件
     （路径：系统和安全 → Windows Defender 防火墙 → 左侧
       "启用或关闭 Windows Defender 防火墙"）
   ▶ 系统：查看电脑配置；左侧"高级系统设置"里还有：
     · 计算机名：改电脑在局域网里显示的名字
     · 性能设置："高级"→ 性能"设置"→ 视觉效果
       ——电脑卡顿可勾"调整为最佳性能"关掉所有动画特效
     · 环境变量、远程协助
     · 系统保护：创建"还原点"（改设置前的后悔药）★建议学会
   ▶ 电源选项：
     · 选电源计划：平衡 / 高性能 / 节能
     · "选择电源按钮的功能"：按电源键是关机/睡眠/不动作
     · "更改计算机睡眠时间"：多久不碰就睡眠/关屏
   ▶ Windows 工具（Win10 叫"管理工具"）：系统自带高级工具合集
     （服务、磁盘清理、碎片整理、任务计划程序、计算机管理等）
   ▶ 存储空间、文件历史记录、备份和还原

2. 网络和 Internet
   ▶ 网络和共享中心：
     · 看当前连接的是什么网络
     · 改网络类型：公用（更安全）/专用（家里可共享文件）
     · 左侧"更改适配器设置"：禁用/启用网卡、右键诊断网络
     · 左侧"更改高级共享设置"：网络发现、文件打印机共享开关
   ▶ Internet 选项：浏览器安全级别、删除浏览临时文件
     （主页等设置现在在 Edge 浏览器内部改）

3. 硬件和声音
   ▶ 鼠标（详见第三部分）
   ▶ 声音 → 播放：默认播放设备；双击设备 → "增强"选项卡
     可开低音增强、虚拟环绕等音效
   ▶ 声音 → 录制：默认麦克风；双击麦克风 → "级别"选项卡
     拉高滑块（对方听你声音小就在这调）
   ▶ 声音 → 声音：Windows 系统提示音方案（可换整套系统音效）
   ▶ 电源选项（同上）、设备和打印机、自动播放

4. 用户账户
   ▶ 更改账户类型、管理另一个账户
   ▶ 更改用户账户控制(UAC)设置：拖滑块调节"安装软件时
     弹不弹黑色确认框"，默认从上往下第二格最合适（勿拉到底）
   ▶ 凭据管理器：管理记住的网站/网络密码

5. 外观和个性化
   ▶ 显示：放大缩小所有内容
   ▶ 任务栏和导航：任务栏设置的老入口
   ▶ 文件资源管理器选项 ★非常常用★
     打开步骤：控制面板 → 外观和个性化 → 文件资源管理器选项
     （或：打开任意文件夹 → 顶部"…" → "选项"）
     "查看"标签页里最有用的两项：
     · 显示隐藏的文件/文件夹：选"显示隐藏的文件、文件夹和驱动器"
     · 显示文件扩展名：取消勾选"隐藏已知文件类型的扩展名"
       （改名、防病毒都需要看到 .txt .jpg .exe 这样的后缀）
     Win11 也可以在文件夹顶部：查看 → 显示 → 勾选
     "文件扩展名"和"隐藏的项目"
   ▶ 轻松使用设置中心、索引选项、字体

6. 时钟和区域
   ▶ 日期和时间：改时间的另一个入口；"Internet 时间"标签页
     可点"立即更新"与微软时间服务器对时
   ▶ 区域：格式、位置；"管理"标签 → "更改系统区域设置"
     （老软件中文显示乱码时，把这里改成"中文(简体，中国)"）
   ▶ 语言：输入法的老入口

7. 程序
   ▶ 程序和功能：卸载/修复/更改已安装的软件
   ▶ "启用或关闭 Windows 功能"：勾选安装系统自带但默认
     没启用的功能（如 .NET、Hyper-V、旧版 IE 模式、媒体功能）
   ▶ 默认程序：设默认浏览器/播放器的老入口

8. 轻松使用：无障碍功能的全部老入口

【查看方式技巧】把控制面板右上角"查看方式"改为"大图标"，
所有设置项（鼠标、键盘、声音、显示、电源选项……）会直接
平铺排列，找起来更快。


───────────────────────────────────────────────────────────────
第六部分：高级管理工具（配合 Win+R 使用更方便）
───────────────────────────────────────────────────────────────

1. 任务管理器 —— 看"电脑在忙什么" ★必学
   打开：Ctrl + Shift + Esc；或右键任务栏 → 任务管理器
   ▶ 进程：哪些软件在运行、各占多少 CPU/内存；
     软件卡死 → 选中它 → 点右下角"结束任务"
   ▶ 性能：CPU、内存、磁盘、网络的实时曲线图
   ▶ 启动应用：管理开机自启动（常用，见板块 5）
   ▶ 用户：各登录账户的资源占用
   ▶ 详细信息 / 服务：更底层的进程和服务列表

2. 设备管理器 —— 管"硬件和驱动"
   打开：右键开始按钮 → 设备管理器（或按 Win + X）；
   或 Win+R → 输入 devmgmt.msc
   ▶ 设备前有黄色感叹号 = 该硬件驱动没装好
   ▶ 更新驱动：右键设备 → 更新驱动程序 → 自动搜索驱动程序
   ▶ 禁用/启用设备：如想暂时关掉摄像头、触摸板
   ▶ 卸载设备：设备异常时卸载后重启，让系统重装

3. 磁盘管理 —— 管"硬盘分区"
   打开：右键开始按钮 → 磁盘管理（或按 Win + X）
   ▶ 新装的硬盘要先"新建简单卷"才会出现在"此电脑"里
   ▶ 压缩卷：从大分区里分出一块空间
   ▶ 扩展卷：把相邻空闲空间并入某个分区
   ▶ 更改驱动器号和路径：把 D 盘改成 E 盘这类盘符
   ▶ 格式化：清空整个分区 ⚠数据全没，三思后行
   ▶ 删除卷 ⚠危险操作，新手不要点

4. 服务 —— Windows 后台服务
   打开：Win+R → services.msc；或任务管理器 → 服务 → 打开服务
   ▶ 找到服务 → 右键 → 属性 → "启动类型"改为
     自动 / 手动 / 禁用
   ▶ 常见例子：打印机服务 Print Spooler、蓝牙支持服务
   ⚠ 不认识的服务不要乱禁用，可能造成系统异常

5. 系统配置 (msconfig)
   打开：Win+R → msconfig
   ▶ "常规"→"诊断启动"：只加载基本服务，排查卡顿利器
   ▶ "引导"→勾"安全引导"：重启进入安全模式杀毒/排错
     （记得用完取消勾选！）
   ▶ "服务"：勾"隐藏所有 Microsoft 服务"后可批量禁用第三方服务

6. 注册表编辑器 ⚠高危区域
   打开：Win+R → regedit
   ▶ Windows 最底层的设置数据库，一些"优化教程"会让你改它
   ▶ 新手原则：能不改就不改；改前一定"文件→导出"备份；
     改错可能导致系统无法开机
   ▶ 没有把握时，跳过任何要求改注册表的教程

7. 本地组策略（本机为专业版，可用；家庭版会提示找不到）
   打开：Win+R → gpedit.msc
   ▶ 批量管控系统行为的高级设置，如关闭自动播放、
     锁定策略等，适合有经验的用户

8. 计算机管理（一个大合集）
   打开：右键"此电脑" → 管理；或 Win+R → compmgmt.msc
   ▶ 包含：任务计划程序、共享文件夹、本地用户和组、
     性能、设备管理器、磁盘管理、服务和应用程序

9. 其他实用工具（Win+R 输入名字回车即可打开）
   · msinfo32 —— 系统信息：查详细配置
   · dxdiag —— DirectX 诊断：查显卡/声卡信息
   · resmon —— 资源监视器：比任务管理器更细
   · eventvwr —— 事件查看器：查系统日志、蓝屏原因
   · cleanmgr —— 磁盘清理：清系统垃圾
   · dfrgui —— 碎片整理和优化驱动器（机械硬盘用）
   · mdsched —— 内存检测：怀疑内存条故障时用
   · main.cpl —— 鼠标属性（同控制面板鼠标）
   · sysdm.cpl —— 系统属性（性能/计算机名/系统保护/远程）
   · ncpa.cpl —— 网络连接（网卡管理）
   · intl.cpl —— 区域；timedate.cpl —— 日期时间
   · desk.cpl —— 显示设置
   · control printers —— 打印机列表
   · taskmgr —— 任务管理器；control —— 控制面板
   · calc —— 计算器；notepad —— 记事本；mspaint —— 画图
   · winver —— 查看 Windows 版本号
   · osk —— 屏幕键盘；snippingtool —— 截图工具

───────────────────────────────────────────────────────────────
第七部分：BIOS / UEFI 设置（开机时才能进入的设置）
───────────────────────────────────────────────────────────────
【是什么】BIOS/UEFI 是主板上的"最底层设置"，电脑通电后最先
运行。Windows 里的不少功能（虚拟化、启动顺序等）源头在这里。

一、怎么进入（两种方法）
  方法 1：开机瞬间按特定键
    ① 点 开始 → 电源 → 重启（关机状态则按开机键）
    ② 屏幕刚亮、出现品牌 logo 时，快速反复点按对应按键：
       · 组装机主板：技嘉/微星 Del 或 F2；华硕 F2 或 Del；
         七彩虹 Del
       · 品牌机/笔记本：戴尔 F2；惠普 F10 或 Esc；
         联想笔记本 F2（部分需 Fn+F2）、联想台式 F1；
         华硕笔记本 F2；宏碁 F2；三星 F2；微星笔记本 Del
       · 记不住就开机时把 Del、F2、F10、F12 依次试一遍
    ③ 进入后一般是蓝/灰底色的英文界面
    ⚠ 操作方式：方向键移动、回车进入、Esc 返回、F10 保存退出
  方法 2：从 Windows 里进入（Win11 最稳，推荐）★
    设置 → 系统 → 恢复 → "高级启动"旁点"立即重新启动" →
    电脑重启进入蓝色菜单后依次选：
    疑难解答 → 高级选项 → UEFI 固件设置 → 重启

二、BIOS 里常见的可设置项（英文界面常见词）
  1. Boot（启动）：调整启动顺序——用 U 盘装系统必须先把
     USB 设为第一启动项（First Boot Device）
  2. Security（安全）：设置开机密码（比 Windows 密码更底层）、
     Secure Boot 安全启动开关
  3. Virtualization（虚拟化）：装虚拟机/安卓模拟器/WSL 必须开
     （名称如 Intel VT-x、SVM Mode，改成 Enabled）
  4. 时间日期设置：系统时间不对的源头可能在这
  5. 风扇转速、CPU/内存超频（XMP/EXPO）、RGB 灯光
     ⚠ 超频类设置新手不要动
  6. Load Optimized Defaults / Restore Defaults：恢复默认值
     ——改乱了用它救命（很多主板按 F9 也能载入默认）

第八部分：常用快捷键速查表（记住能省一半操作）
───────────────────────────────────────────────────────────────

【右键菜单里藏着的设置入口（很容易被忽略）】
· 桌面空白处右键 → 显示设置 / 个性化 / 新建 /
  NVIDIA·AMD·Intel 显卡控制面板（分辨率、色彩、游戏画质在里面）
· 任务栏空白处右键 → 任务栏设置 / 任务管理器
· 任务栏 Wi-Fi 图标右键 → 网络和 Internet 设置 / 疑难解答
· 任务栏音量图标右键 → 声音设置 / 音量混合器
· 任务栏电池图标右键 → 电源和睡眠设置
· "此电脑"右键 → 属性(关于) / 管理(计算机管理) / 映射网络驱动器
· 文件夹空白处右键 → 查看（图标大小、排序、显示隐藏项目）→ 选项
· 开始按钮右键 → 就是 Win+X 那个菜单
· 桌面/文件夹里"此电脑"图标 → 属性 → 可看配置、进高级系统设置

───────────────────────────────────────────────────────────────
第九部分：新手必读注意事项
───────────────────────────────────────────────────────────────
1. 改任何设置前，先记住原来的值（最保险：按 Win+Shift+S 截图保存）
2. 一次只改一个设置，确认电脑正常后再改下一个
3. 不认识的选项不要动，尤其：注册表、服务、BIOS 超频项、
   Windows 文件夹（System32 等）
4. 学会创建"还原点"再折腾：
   控制面板 → 系统 → "高级系统设置" → "系统保护"标签 →
   选 C 盘 → 点"创建…"，起个名字（如"改设置前"）
   出问题时在同页面点"系统还原"即可回到创建时的状态
5. 重要资料定期备份到 U 盘/移动硬盘/网盘，
   任何设置都无法 100% 防止硬盘损坏
6. 遇到问题按顺序自救：
   ① 重启电脑（能解决 80% 的问题）
   ② 设置 → 系统 → 疑难解答 → 一键修复
   ③ Windows 更新（打齐补丁）
   ④ 系统还原（回到还原点）
   ⑤ 重置电脑（最后手段，记得先备份）
7. 网上的"优化脚本""改注册表提速"文章鱼龙混杂，
   有疑问认准微软官方帮助：support.microsoft.com
