【第1题】答案：D（ORACLE）
题目：下列软件中，_______是数据库管理系统。
解析：
  数据库管理系统（英文缩写 DBMS）是一种专门用来"存大量数据、管理大量数据"
  的软件，比如学校存所有学生的成绩、银行存所有储户的信息，用的就是它。
  • A. PowerPoint：做幻灯片演示文稿的，不是管数据的。✗
  • B. Excel：是电子表格软件，虽然能算数据，但它不属于正式的"数据库管理系统"。✗
  • C. FrontPage：是做网页的软件。✗
  • D. ORACLE（甲骨文）：世界上著名的大型数据库管理系统。✓
  记忆技巧：ORACLE、SQL Server、Access、MySQL、Sybase 这些都是数据库管理系统。

【第2题】答案：A（WAV）
题目：下列文件扩展名中，________不是常用的图像文件格式。

  补充：常见的音频格式有 WAV、MP3、MIDI、WMA；常见图像格式有 JPG、GIF、BMP、PNG、TIF。

【第4题】答案：A（实现计算机信号和音频信号相互转换）
题目：调制解调器的作用是______________。
解析：
  调制解调器俗称"猫"（英文 Modem，拨号上网用的那个盒子）。
  计算机内部用的是"数字信号"（0 和 1），而普通电话线上传的是"模拟信号"
  （像声波一样的连续信号，属于音频信号）。两种信号不通用，需要转换：
  • "调制"：把计算机的数字信号 → 转成电话线能传的音频模拟信号（发出去时）
  • "解调"：把电话线传来的音频模拟信号 → 转回计算机能懂的数字信号（收到时）
  所以它的作用就是"数字信号与音频（模拟）信号相互转换"，选 A。
  • B 视频信号、C 二进制信号、D 防病毒，都不是 Modem 干的事。✗

【第8题】答案：A（顺序结构、分支结构和循环结构）
题目：高级语言的基本程序控制结构是指___________。

  • 分支结构（也叫选择结构）：遇到条件判断走哪条路（"如果…就…否则…"）。
  • 循环结构：重复做某件事（"重复 100 次"）。
  这就是著名的"结构化程序设计"三结构，选 A。✓
  • B"输入、处理、输出"说的是数据处理过程；D"数据类型、表达式、语句"是
    语言的基本成分——都不是"控制结构"。✗

【第19题】答案：A（二进制数 111100）
题目：下列用不同数制表示的数中，数值最小的数是___________。
解析：
  不同进制不能直接比大小，先把它们全换算成十进制：
  • 二进制 111100：从右往左每位代表 1,2,4,8,16,32
    = 1×32 + 1×16 + 1×8 + 1×4 + 0×2 + 0×1 = 32+16+8+4 = 60
  • 八进制 77：每位代表 1,8 → 7×8 + 7×1 = 56 + 7 = 63
  • 十进制 68：就是 68
  • 十六进制 5F：每位代表 1,16；F 代表 15 → 5×16 + 15×1 = 80 + 15 = 95
  比较：60 < 63 < 68 < 95，最小的是二进制 111100（=60）。✓ 选 A。

【第20题】答案：D（1024）
题目：1KB 的存储容量最多可以存储__________个字符。
解析：
  电脑里存东西的最小单位是"字节"（Byte），一个英文字符（字母、数字、
  标点）正好占 1 个字节。
  换算关系：1KB = 1024B（字节），注意不是 1000！

  所以 1KB 能存 1024 个字符。✓ 选 D。
  • B 512 是 1024 的一半，用来迷惑你；C 1000 是按十进制想当然了。✗

  • MPEG-4：网络流媒体视频（ MP4 ）

  VCD 用 MPEG-1，选 A。✓

【第28题】答案：C（QQ、微信）
题目：下列选项中，___________都属于即时通信模式。
解析：
  即时通信（IM）的特点：双方同时在线、消息立刻送达、可以实时聊天。
  • A. QQ✓是即时通信，但"短信"是手机电信业务、"E-Mail"是异步邮件
    （发出去等对方有空再看），后两个不算。✗
  • B. 微信✓算，但"微博"是社交媒体（发帖给别人看，不是点对点实时聊）、
    "短信"不算。✗
  • C. QQ、微信：两个都是标准的即时通信软件。✓
  • D. 多了个"微博"不算。✗

【第29题】答案：A（存储程序和程序控制）
题目：目前使用的微机是基于_________原理进行工作的。
解析：
  现代计算机都遵循"冯·诺依曼"体系结构，其核心思想是
  "存储程序"（程序和数据事先存入存储器）+ "程序控制"
  （计算机自动按程序一步步执行）。
  选 A。✓
  • B 人工智能、C 数字控制（数控机床）、D 集成电路（硬件制造技术）
    都不是计算机的基本工作原理。✗

【第30题】答案：D（结构化查询语言）
题目：术语"SQL"指的是_________。
解析：
  SQL = Structured Query Language = 结构化查询语言，
  是操作数据库（查询、插入、修改、删除数据）的标准语言。
  选 D。✓
  • A 数据库结构、B 数据库系统、C 数据模型都不是 SQL 的含义。✗

【第31题】答案：A（SMTP）
题目：下列协议中，_____________是邮件传输协议。
解析：
  • A. SMTP（简单邮件传输协议）：专门负责"发/传"邮件。✓
  • B. HTTP：超文本传输协议，用于浏览网页。✗
  • C. FTP：文件传输协议，用于上传下载文件。✗
  • D. ARP：地址解析协议，用于把 IP 地址翻译成网卡地址。✗

【第32题】答案：A（Dim）
题目：下列标识符中，_______不是 VB 中的数据类型名。
解析：

    它不是数据类型。✓（本题选它）
  • B. Integer 整型✓是类型、C. Boolean 布尔型✓是类型、D. String 字符串✓是类型。✗

【第33题】答案：C（编码）
题目：软件生命周期包括需求分析、总体设计、详细设计、_____、测试和维护等几个阶段。

【第34题】答案：D（保护内网不被非法入侵）

  • A 提高网速：防火墙不提速反而略微降速。✗
  • B 防数据丢失：那是数据备份/容灾干的事。✗
  • C 信息加密：那是加密软件/协议（如 SSL）干的事。✗

【第35题】答案：B（实现某种操作的特殊代码）
题目：Access 中的"宏"是一种_______。
解析：
  Access 是微软 Office 里的小型数据库软件。"宏"是 Access 中的一个对象，

  一段特殊的代码，以后只要运行这个宏，这一串操作就会自动完成。
  所以宏是"实现某种操作的特殊代码"。✓ 选 B。
  • A 数据安全机制✗、C 数据视图✗、D 报表生成工具✗，都不对。

【第36题】答案：C（用于存放固定不变的程序和数据）
题目：在计算机内存储器中，ROM 的作用是__________。
解析：
  内存分两种：
  • ROM（只读存储器）：断电数据也不丢，出厂时写好了内容，一般不能再改。
    用来存放固定不变的程序和数据，比如开机自检程序（BIOS）就存在 ROM 里，
    所以一开机电脑就知道该干什么。✓ 选 C。
  • RAM（随机存储存储器）：可以随便读写，但一断电数据全没，
    用来临时存放正在运行的程序和数据（D 选项说的是 RAM 的作用）。✗
  • A 保证可靠性、B 预防病毒：ROM 没有这些功能。✗

【第37题】答案：B（传输层）
题目：TCP/IP 协议包括网络接口层、互联层、_________和应用层。
解析：
  TCP/IP 是互联网使用的协议体系，共分 4 层（从下到上）：
    网络接口层 → 互联层（网际层） → 传输层 → 应用层
  空格处填"传输层"。✓ 选 B。
  • 物理层、表示层、会话层是 OSI 七层模型里的名字，TCP/IP 四层模型中没有
    单独的这三层。✗
  记忆：TCP 工作在传输层，IP 工作在互联层。

【第38题】答案：B（CAD）
题目：计算机辅助设计是计算机应用的一个重要方面，它的英文缩写是__________。
解析：
  计算机辅助系列缩写（必背）：
  • CAD = Computer Aided Design = 计算机辅助设计（画工程图纸、建筑图）✓
  • CAM = Computer Aided Manufacturing = 计算机辅助制造
  • CAE = Computer Aided Engineering = 计算机辅助工程
  • CAI = Computer Aided Instruction = 计算机辅助教学
  本题"辅助设计"选 B（CAD）。✓

【第39题】答案：C（SELECT 姓名，成绩 FROM 学生）
题目：若"学生"表中存储了学号、姓名、成绩等字段，则"查询所有学生的姓名和成绩"
      的SQL语句是___________。
解析：
  SQL 查询语句的基本格式：SELECT 字段名列表 FROM 表名
  • 多个字段之间要用"英文逗号"隔开。
  • A. SELECT * FROM 学生：星号*代表"所有字段"，查出来的是学号+姓名+成绩
    全部列，而题目只要"姓名和成绩"两列。✗
  • B. SELECT 姓名 成绩 FROM 学生：两个字段之间少了逗号，语法错误。✗
  • C. SELECT 姓名，成绩 FROM 学生：字段之间有逗号分隔，正确。✓
  • D. SELECT 姓名、成绩 FROM 学生：用了中文顿号"、"，SQL 不认，语法错误。✗
  （严格来说 C 里最好用英文逗号,但四个选项中只有 C 结构正确，选 C。）

【第40题】答案：A（1）
题目：Access 中，同时打开数据库文件的数量最多是______。
解析：
  Access 的规定：一个 Access 窗口（实例）中同一时间只能打开并使用
  1 个数据库文件。要打开另一个数据库，就必须先关闭当前这个。
  所以"同时打开数据库文件的数量最多是 1 个"。✓ 选 A。

  射手榜（数据在 A1:E36，第 1 行是表头"球员名 球队名称 进球总数 普通进球数 点球数"）。

【第0步】打开文件
  双击 ex.xlsx 打开 Excel。窗口底部能看到"积分榜 / Sheet1 / 射手榜"三个标签。

【第1步】删除 Sheet1 工作表
  1. 看窗口底部的工作表标签，在【Sheet1】标签上点鼠标【右键】。
  2. 在弹出的菜单里点【删除】。
  3. Sheet1 标签消失即成功。（Sheet1 是空表，删除不影响数据。）

【第2步】在"积分榜"A1 输入标题并合并居中、设置字体
  1. 点底部【积分榜】标签切换到该表。
  2. 用鼠标点一下 A1 单元格（第 1 行第 A 列交叉的格子），输入：
     2013-2014赛季英超积分榜   然后按回车。
  3. 选中 A1 到 H1：点 A1 单元格，按住左键往右拖到 H1（共 8 个格子）。
  4. 点击【开始】选项卡 → "对齐方式"区域 → 点【合并后居中】按钮
     （图标是一个带向右箭头的 ab| 框）。
  5. 保持选中这个合并单元格，仍在【开始】选项卡：
     - "字体"框选【黑体】；
     - 点【加粗】按钮（字母 B 图标）；
     - "字号"框选【20】。

【第3步】H 列用公式计算积分（积分=胜场×3+平局×1）
  积分榜数据结构：第 2 行是表头（序号/球队名称/总场次/胜场数/平局数/负场数/
  进球数/积分），球队数据在第 3~22 行。其中：
    D列=胜场数，E列=平局数，H列=积分（要填的空列）。
  1. 点 H3 单元格（第 3 行、H 列交叉处，即"水晶宫"那一行的积分格）。
  2. 在 H3 中输入公式：=D3*3+E3   然后按回车。
     （意思是：胜场数×3分 + 平局数×1分 = 积分，负场 0 分不用算。）
     按回车后 H3 显示 45（13×3+6=45）。
  3. 自动填充：再点一下 H3，把鼠标移到 H3 单元格【右下角的小方块】上，
     鼠标会变成黑色实心"＋"（叫填充柄）。按住左键【往下拖】到 H22 松手，
     所有球队的积分都算出来了。
     （或者：双击填充柄，自动填充到与左侧数据齐平的最后一行。）
  4. 检查几个：利物浦行应显示 26*3+6=84；曼城行应显示 27*3+5=86；
     曼联行应显示 19*3+7=64。

【第4步】A 列填充序号 1、2、3……
  A3:A22 目前是空的（A2 表头"序号"）。
  方法一（最快——填充序列）：
  1. 点 A3，输入 1，回车；再点 A4，输入 2，回车。
  2. 选中 A3 和 A4 两个格子（按住左键从 A3 拖到 A4）。
  3. 把鼠标移到选区右下角的小方块（填充柄）上，变成黑"＋"后按住左键
     往下拖到 A22 松手，自动填出 3、4、5……20。
  方法二（菜单法）：
  1. 在 A3 输入 1，选中 A3:A22 → 【开始】→"编辑"区域→【填充】按钮→
     【序列】→ 类型选"等差序列"、步长值 1 → 确定。

【第5步】A2:H22 水平居中
  1. 点 A2 单元格，按住左键拖到 H22（或者点 A2 后按住 Shift 再点 H22），
     选中表头加全部数据。
  2. 【开始】选项卡 → "对齐方式"区域 → 点【居中】按钮（几条横线居中的图标）。

【第6步】A2:H22 边框（内框最细单线红色、外框双线蓝色）
  1. 保持选中 A2:H22，点击【开始】选项卡 → "字体"区域 → 【边框】按钮
     （一个田字格图标）右边的小箭头 → 选【其他边框】，弹出"设置单元格格式"
     对话框并停在【边框】选项卡。
  2. 先做内部线：
     - "线条"样式列表里选最细的【单实线】（左上第一根）；
     - "颜色"下拉框选【标准色-红色】；
     - 点"预置"里的【内部】按钮。
  3. 再做外框线：
     - "线条"样式选【双线】（双横线样式）；
     - "颜色"选【标准色-蓝色】；
     - 点"预置"里的【外边框】按钮。
  4. 看右下预览框：外圈蓝色双线、内部红色细线，对了就点【确定】。

【第7步】射手榜自动筛选"曼联"
  1. 点底部【射手榜】标签切换工作表。
  2. 选中数据区域：点 A1（表头"球员名"），拖选到 E1（或直接点任意一个有数据的
     格子）。稳妥起见选中 A1:E1 表头行。
  3. 【开始】选项卡 → "编辑"区域 → 【排序和筛选】按钮 → 点【筛选】。
     表头每个单元格出现下拉小箭头 ▼。
     （也可用【数据】选项卡 → "排序和筛选"区域 → 【筛选】按钮。）
  4. 点击 B1"球队名称"格的▼箭头 → 弹出列表：
     - 把"(全选)"的勾去掉；
     - 只勾选【曼联】（注意素材里有的球队名带空格，认准"曼联"两项都勾上
       以防万一）；
     - 点【确定】。
  5. 筛选后只显示曼联的球员：亚亚-图雷(20球)、鲁尼(17球)、范佩西(12球)、
     维尔贝克(9球)，共 4 行（第 4、7、13、17 行）。

【第8步】根据筛选结果做簇状柱形图
  1. 筛选状态下，选中这 4 名球员的 A 列和 C 列数据：
     方法：先选中 A4:A7 区域（球员名），按住 Ctrl 键再选 C4:C7（进球总数）
     ——这样两块不连续区域一起选中（具体行号以你筛选后的实际显示为准）。
  2. 点击【插入】选项卡 → "图表"区域 → 点【柱形图/插入柱形图】按钮 →
     在下拉列表的"二维柱形图"中选第一个【簇状柱形图】。
  3. 图表插入后，点击图表 → 顶部出现【图表工具】（含"设计""格式"）：
     改标题：直接点图表顶部的"图表标题"文字，改成：曼联球员进球总数统计
     （若没有标题：【图表工具-设计】→【添加图表元素】→【图表标题】→
     【图表上方】，再输入标题文字。）
  4. 去掉图例：【图表工具-设计】→【添加图表元素】→【图例】→【无】。
  5. 显示数据标签（放数据点结尾之外）：
     【图表工具-设计】→【添加图表元素】→【数据标签】→【数据标签外】
     （"数据标签外"就是把标签放在柱子顶端之外/结尾之外）。
  6. 把图表拖放到数据表旁边空白处摆好（不要盖住数据）。

【第9步】保存
  按 Ctrl+S 保存 ex.xlsx。
  ⚠ 题目要求"除题目要求外不得增加、删除、移动工作表中内容"，
  操作时别乱动别的格子。

第四部分：PowerPoint 大题（营养食物.pptx）超详细操作步骤
════════════════════════════════════════════════════════════

★ 素材位置：D:\gitProject\teach20251126\wps\20260821\函授新题\2\2\营养食物.pptx
★ 演示文稿共 10 张幻灯片：
  第1张：标题"营养讲座"（封面）
  第2张：营养含义
  第3张：营养食物（SmartArt 图，含 7 项：糙米、红薯、红薯叶、番茄、卷心菜、
          巨峰葡萄、香蕉）——这张是"目录"页，第 4~10 张分别详细介绍这 7 种食物。

【第0步】打开文件
  双击 营养食物.pptx 打开 PowerPoint。
  左侧是幻灯片缩略图窗格，点缩略图可在各张之间切换。

【第1步】所有幻灯片设置设计主题为"华丽"
  1. 点左侧第 1 张幻灯片缩略图，再按 Ctrl+A 不行（那会全选对象），
     正确做法：随便停在任意一张幻灯片上即可（主题应用于全部不用全选）。
  2. 点击【设计】选项卡（窗口顶部中间）。
  3. 在"主题"区域浏览样式，找到名为【华丽】的主题：
     - 根据 Office 版本，主题按主题名排序（拼音/字母顺序），鼠标悬停在每个
       主题上会显示名称提示，找到"华丽"（英文版叫 Flow）。
     - 若区域里显示不全，点主题区右侧的【其他】下拉箭头（v 形）展开全部。
  4. 在【华丽】主题上点【右键】→ 选【应用于所有幻灯片】
     （直接左键点击通常也会应用到全部，右键方式最保险）。

【第2步】第 1 张标题"营养讲座"设为微软雅黑、54 号
  1. 在左侧缩略图窗格点【第 1 张】幻灯片。
  2. 在中间编辑区找到大标题"营养讲座"，在文字上按住左键拖动选中这几个字
     （变蓝/变选中状态）。
     （若点进去发现选不中，先单击标题框，再拖选文字。）
  3. 点【开始】选项卡：
     - "字体"下拉框选【微软雅黑】；
     - "字号"下拉框选【54】（没有 54 就手动输入 54 再回车）。

【第3步】所有幻灯片切换效果：淡出、持续 1 秒、照相机声音
  1. 点左侧第 1 张幻灯片（保证当前在第 1 张）。
  2. 点击【切换】选项卡（在"开始"右边、"设计"旁边）。
  3. "切换到此幻灯片"区域：选择【淡出】效果（细微型一排里，一个圆圈渐隐
     的图标；英文版叫 Fade）。
  4. 右侧"计时"区域：
     - "持续时间"框中把数字改为：01.00（即 1 秒）；
     - "声音"下拉框：点开，选【照相机】（英文 Camera；在下拉列表的
       "其他声音"上方一排）。
  5. 关键：点击最右边【全部应用】按钮！
     （不点它就只有第 1 张有切换效果，点了才会应用到全部 10 张。）

【第4步】第 3 张幻灯片各项文字建超链接指向相应标题的幻灯片
  背景：第 3 张是一个 SmartArt 图（7 个食物名围着排列），要把每个食物名
  链接到对应详细介绍的幻灯片（第4~10张）。
  1. 左侧点【第 3 张】幻灯片。
  2. 在 SmartArt 中找到"糙米"两个字：双击进入 SmartArt，单击"糙米"所在
     形状，再拖选其中"糙米"文字（变选中）。
     （如果个别项已有链接但链错了，也要先改选中再重新设置覆盖它——
      这就是题目说的"创建或修正超链接"。）
  3. 点【插入】选项卡 → "链接"区域 → 点【超链接】按钮（一个地球加链条的
     图标），或直接按 Ctrl+K。
  4. 弹出"插入超链接"对话框：
     - 点左侧"链接到"列表中的【本文档中的位置】；
     - 中间"请选择文档中的位置"列表会列出：第一张幻灯片、下一张幻灯片、
       上一张幻灯片、最后一张幻灯片、幻灯片标题……
     - 选择标题为【糙米】的那张幻灯片（第 4 张，列表里显示"4. 糙米"）；
     - 点【确定】。设置成功后"糙米"文字会变色加下划线。
  5. 同样方法处理其余 6 项（每项都链接到同名标题的幻灯片）：
     - "红薯"→ 第 5 张（红薯）
     - "红薯叶"→ 第 6 张（红薯叶）
     - "番茄"→ 第 7 张（番茄）
     - "卷心菜"→ 第 8 张（卷心菜）
     - "巨峰葡萄"→ 第 9 张（巨峰葡萄）
     - "香蕉"→ 第 10 张（香蕉）
  6. 检查：放映时（按 F5 到第 3 张）点每个词，应跳到对应幻灯片。

【第5步】第 3 张标题"营养食物"动画：自右侧切入、延迟 1 秒
  1. 仍在第 3 张幻灯片，单击标题"营养食物"（选中整个标题文本框，
     边框变实线）。
  2. 点击【动画】选项卡 → "动画"区域：
     - 在动画样式库里找【切入】效果（"进入"类动画，图标是一个黄色方块
       进入的样子；英文叫 Peek In）。
     - 库里没有就点区域右下角小箭头打开"更改进入效果"对话框 →
       "温和型"或"基本型"里找【切入】→ 确定。
  3. 设置方向：选了切入后，右边出现【效果选项】按钮 → 点开 → 选【自右侧】。
  4. 设置延迟：右侧"计时"区域 → "延迟"框输入：1 秒（点框输 01.00 或 1）。
     （"开始"保持"单击时"即可，题目未特别要求。）

【第6步】放映方式：循环放映，按 ESC 键终止
  1. 点击【幻灯片放映】选项卡。
  2. "设置"区域 → 点【设置幻灯片放映】按钮，弹出"设置放映方式"对话框。
  3. 在"放映选项"一栏：
     - 勾选【循环放映，按 ESC 键终止】。
  4. 点【确定】。

【第7步】页脚插入自动更新日期（XXXX年XX月XX日，标题幻灯片除外）
  1. 点击【插入】选项卡 → "文本"区域 → 点【页眉和页脚】按钮
     （2016+版本在【插入】→"文本"区域→【页眉和页脚】；若看不到，
      点【插入】→【日期和时间】也一样）。
  2. 弹出"页眉和页脚"对话框，停在【幻灯片】选项卡：
     - 勾选【日期和时间】；
     - 选中下面的【自动更新】（而不是"固定"）；
     - 旁边的下拉框里选择格式：【XXXX年XX月XX日】（例如 2013年01月15日
       这种中文年月日格式）。
  3. ⚠ 关键：不要勾"标题幻灯片中不显示"？——恰恰相反，要勾选
     【标题幻灯片中不显示】（题目要求"除标题幻灯片不显示外，
     在其他幻灯片中插入"，所以要勾这一项）。
  4. 点【全部应用】按钮（应用于所有幻灯片，第 1 张标题页会自动不显示）。

【第8步】保存
  按 Ctrl+S 保存 营养食物.pptx。

1. Word 页面设置"每页 38 行、每行 38 字符"必须先选"指定行和字符网格"。
2. Word 替换"银行"时，格式一定要挂在"替换为"框上（光标先点进替换框再设格式）。
3. 选择性粘贴必须选"图片（增强型图元文件）"，不是普通"粘贴"或"选择性粘贴-
   HTML 格式"。
4. 分栏只选"倒数第二段"，别把最后一段也选进去；记得勾"分隔线"和"栏宽相等"。
5. Excel 积分公式 =D3*3+E3，注意是先选中 H3 再输入；填充柄拖到第 22 行。
6. 边框：内框和外框分开设置，先选线型颜色再点"内部/外边框"按钮。
7. 图表：无图例 + 数据标签外 + 图表上方标题，三个都要做。
8. PPT 切换效果设置完一定要点【全部应用】。
9. 日期选"自动更新"，并勾选"标题幻灯片中不显示"。
10. 所有文件改完按 Ctrl+S 保存，保存格式保持原格式（rtf/xlsx/pptx）。
