【第1题】答案：B（网络接口层）
题目：TCP/IP协议包括____、互联层、传输层和应用层。
详细解析：
TCP/IP 是互联网上通用的"通信规则"（协议），它把网络通信分成4层，从下到上依次是：
    网络接口层 → 互联层 → 传输层 → 应用层
就像寄快递：网络接口层负责把包裹（数据）交给快递车；互联层负责选路线；传输层保证包裹不丢；应用层就是你写的信的内容。
其他选项为什么错：物理层、会话层、表示层，这些是另一个体系"OSI七层模型"里的名字（OSI共7层：物理、数据链路、网络、传输、会话、表示、应用），TCP/IP只有4层，没有单独的它们。TCP/IP最底下那层叫"网络接口层"，所以选B。

【第2题】答案：C（设置计算机口令）
题目：下列措施中，____对预防计算机病毒不起作用。
详细解析：
这道题要选"没用的"那个。
A 安装防火墙：防火墙像小区门卫，能拦截通过网络进来的病毒和攻击，有用。
B 安装防病毒软件：杀毒软件能查杀病毒，有用。
C 设置计算机口令：口令（开机密码）是防止别人随便用你电脑的，属于"防人"，病毒该来还是来，它管不了病毒，所以它"不起作用"，选C。
D 对优盘加写保护：写保护就是让U盘"只能读不能写"，病毒想写进U盘也写不进去，能防病毒通过U盘传播，有用。

【第3题】答案：B（网关）
题目：路由器又称为____。
详细解析：
路由器（Router）的作用是把你家的网络连到外面的大网络，并且帮数据"选路"转发。在早期技术文献里，路由器就被叫做"网关（Gateway）"，所以本题选B。
其他选项辨析（这几个设备容易混，考试常考）：
网卡：插在电脑里、负责让电脑能连网的板卡（每台电脑都有）。
网桥：把两段局域网"桥接"起来的设备，工作层次比路由器低。
集线器：多口的中继器，只是把信号"广播"给所有口，现在已经很少用。

【第4题】答案：C（鼠标和键盘）

输入设备=把信息"送进"电脑的设备；输出设备=把电脑处理的结果"拿出来给你看"的设备。
键盘：输入文字，必不可少。鼠标：操作界面，必不可少。→ 鼠标和键盘，选C。

A 和 B 里的"显示器"是输出设备（把画面显示给你看）。

【第5题】答案：B（应用软件的卸载只要直接删除文件即可）
题目：下列说法中，____是不正确的。
详细解析：
选"错误的说法"。
A "大多数软件都必须运用安装程序安装后才能使用"——对，软件一般要双击setup.exe安装。
B "应用软件的卸载只要直接删除文件即可"——错！软件安装时不仅复制了文件，还在系统注册表、系统文件夹里"登记"了很多信息。直接删文件会留下一堆垃圾，正确做法是：控制面板 → 程序和功能（或"添加或删除程序"）→ 选中软件 → 卸载。所以B不正确，选B。
C "Office软件安装过程中需要在系统注册表中设置一些参数"——对，安装确实会写注册表。
D "Office软件运行不正常需要重新安装时，必须先卸载该软件"——对，先卸载再重装更干净。

【第6题】答案：C（Cache）
题目：计算机中访问速度最快的存储器是____。
详细解析：
存储器速度从快到慢排排队：
    Cache（高速缓存）> 内存（RAM/ROM）> 硬盘等外存
Cache 紧挨着CPU，专门给CPU"递数据"，速度最快但容量最小。
RAM 是内存条，断电数据就没了。ROM 是只读存储器，断电不丢但速度也慢于Cache。
硬盘虽然容量大，但它是"仓库"，存取速度最慢。
记忆口诀：离CPU越近越快。所以选C。

Photoshop（简称PS）是Adobe公司出品的经典"图像处理软件"，修照片、做海报都靠它，选B。

【第8题】答案：C（测试）
题目：软件生命周期包括需求分析、总体设计、详细设计、编码、____和维护等几个阶段。
详细解析：
软件生命周期就像人的一生，按顺序是：
    需求分析（搞清楚要做什么）→ 总体设计（画大框架）→ 详细设计（画细节）→ 编码（写程序）→ 测试（找毛病）→ 维护（上线后长期修修补补）
空格在"编码"和"维护"之间，正是"测试"阶段：程序写完必须先测试有没有错误，才能交付，之后进入维护。选C。
"执行""改错""开发"都不是生命周期里这个位置的正式阶段名。

【第9题】答案：A（POP3和SMTP）
题目：电子邮件在Internet上传输一般通过____协议实现。
详细解析：
两个邮件协议要记牢：
SMTP：负责"发"邮件（你写信点"发送"时用它，像邮筒）。
POP3：负责"收"邮件（你点"收件"把信从服务器取下来，像取信）。
一个发一个收，合起来就是 A。
FTP是"文件传输协议"（传文件用的，不是邮件）；OSI是网络体系结构模型，不是传输邮件的协议。所以其他选项都错。

【第10题】答案：B（健壮性）
题目：算法的评价指标包括正确性、可读性、____、时间复杂性、空间复杂性等。
详细解析：
评价一个算法好不好，教科书标准5条：
    正确性（结果对不对）、可读性（别人看得懂吗）、健壮性（遇到乱输入会不会崩）、时间复杂性（跑得快不快）、空间复杂性（占内存多不多）
空缺处就是"健壮性"，指算法对错误输入（非法数据）的抵抗、处理能力，选B。
"输入""输出"是算法的特征（算法有0个或多个输入、1个或多个输出），不是评价指标；"容错性"是干扰词。

【第11题】答案：C（电影卡）
题目：MPEG卡又称____。
详细解析：
MPEG 是运动图像压缩标准（VCD、DVD影像就用它压缩）。早年电脑性能弱，放VCD需要专门的解压卡，叫"MPEG卡"，因为主要用来看电影（VCD影片），俗称"电影卡"，选C。

TV卡：接收电视节目用的。
"视频卡"太笼统，不是MPEG卡的别称。

【第15题】答案：D（结构化查询语言）

【第16题】答案：B（客户/服务器结构）
题目："C/S结构"指的是____。
详细解析：
C/S = Client/Server = 客户机/服务器 结构。
Client=客户机（你电脑上装的软件，如QQ客户端），Server=服务器（提供服务的机器）。客户端负责界面，服务器负责数据和处理。选B。
对比记忆：B/S = Browser/Server = 浏览器/服务器 结构（不用装软件，开浏览器就能用，如网页版系统）。选项D是B/S，别混。

【第17题】答案：B（外存储器）
题目：计算机中的存储器分为主存储器和____。
详细解析：
存储器体系二分法：
    存储器 = 主存储器（内存，速度快、容量小、断电丢数据） + 外存储器（硬盘、U盘、光盘，速度慢、容量大、断电不丢）
U盘、光盘只是外存储器中的"个别成员"，不能代表整个类别，所以选"外存储器"这个总称B。
缓冲存储器（Cache）属于另一套分类（CPU缓存），不与主存并列在此。

【第18题】答案：A（第四代）

计算机"代"的划分看元器件：

【第19题】答案：B（数据链路层）
题目：交换机工作在OSI的____。
详细解析：
常见网络设备与OSI层次对应关系（高频考点）：
    集线器 → 物理层（第1层）
    交换机、网桥 → 数据链路层（第2层）
    路由器 → 网络层（第3层）
交换机是根据MAC地址（网卡地址）转发数据的，MAC地址是数据链路层的东东，所以交换机工作在数据链路层，选B。

【第20题】答案：B（机内码）
题目：下列编码中，____用于汉字的存取、处理和传输。
详细解析：
汉字有4种编码，各管一段，要分清：
区位码：输入用（把汉字编成4位数字，如"中"是5448），是一种输入方法。
国标码（交换码）：不同计算机系统之间"交换"汉字信息时用。
机内码：汉字在计算机内部"存储、处理、传输"时用的编码（把国标码每个字节最高位置1得到，避免与ASCII码混淆）。
字形码：输出显示、打印用的（点阵字形，决定字长什么样）。
题目说"存取、处理和传输"——计算机内部的事，选机内码B。

【第22题】答案：B（1024GB）
题目：在存储容量表示中，1TB等于____。
详细解析：
存储单位换算链（相邻进率1024）：
    1KB = 1024B
    1MB = 1024KB
    1GB = 1024MB
    1TB = 1024GB
所以 1TB = 1024GB，选B。硬盘厂商按1000算（所以买的1TB硬盘显示约931GB），但考试按1024算。

【第23题】答案：D
题目："查询所有姓张的学生姓名"的SQL语句是____。
详细解析：
"所有姓张的"=模糊查询，SQL里要用两个东西：
    ① LIKE（像……一样）做模糊匹配；
    ② 通配符 %（百分号）表示"任意多个任意字符"。"张%"就是"张"开头、后面随便。
    ③ 字符串要加引号："张%"。
正确写法：SELECT 姓名 FROM 学生 WHERE 姓名 LIKE "张%"
逐个排雷：
A：用了 =（等号只能精确等于，不能配通配符），错。
B：LIKE 后面的 张% 没加引号，语法错。
C：SELECT * 是查所有字段（题目只要姓名），且 LIKE 张 意思完全不对，错。
D：完全符合语法，选D。

【第24题】答案：C（If语句和Select Case语句）
题目：VB中实现分支结构的语句有____。
详细解析：
程序三大结构：顺序、分支（选择）、循环。
分支=程序走到岔路口，按条件选一条路走。VB里实现分支的是：
    If 语句（如果……就……否则……）
    Select Case 语句（多路开关，按情况选一个）
选C。
其他选项全是"循环"语句：For（计数循环）、Do While（当型循环）、While、Loop——它们负责"重复做"，不负责"选路"。（Repeat是Pascal语言的循环语句，VB里没有。）

【第25题】答案：B（FrontPage）

【第26题】答案：B（串行或USB）
题目：微机中使用的鼠标器通常通过____接口与主机相连接。
详细解析：
鼠标是"一位一位串着传数据"的设备：
早年鼠标接"串行接口"（COM口，梯形9针那种）；现在的鼠标都接USB口。USB也属于串行方式。所以答案是"串行或USB"，选B。
排雷：并行口一般接老式打印机；IDE接硬盘/光驱；SCSI接扫描仪等高端老设备——都不是鼠标用的。

【第27题】答案：A（实现计算机信号和音频信号相互转换）
题目：调制解调器的作用是____。
详细解析：
调制解调器 = Modem = 猫。早年上网走电话线，电话线传的是"音频模拟信号"，电脑只认"数字信号"（0和1），两边语言不通，需要翻译官：
    调制：把电脑的数字信号 → 变成电话线的音频模拟信号（发出）
    解调：把电话线来的模拟信号 → 变回数字信号（接收）
一来一回，就是"相互转换"，选A。
B"视频信号"、C"转换为二进制"（数字信号本来就是二进制）、D"防病毒"都错。

【第28题】答案：D（用高级语言或汇编语言编写的程序）
题目：计算机源程序是____。
详细解析：
源程序（源代码）= 程序员亲手写的"原始程序"。
用高级语言（C、Java等）或汇编语言写的程序，人能读懂但机器不能直接执行，必须经过"翻译"（编译/解释）变成机器语言才能运行——这种"翻译前的原始程序"就叫源程序。选D。
排雷：用机器语言（0和1）直接写的程序机器能直接执行，那是"目标程序/机器语言程序"，不是源程序；A、B 的说法范围不对。

【第29题】答案：B（写入只能一次，但读出可以反复多次）
题目：CD-R光盘的特性是____。
详细解析：
光盘家族三兄弟（首字母区别）：
CD-ROM：只能读，不能写（买来什么样就什么样，如音乐CD、软件盘）。
CD-R：R=Recordable可记录。只能"刻录一次"，刻完就像CD-ROM一样，可以反复读无数次，但不能再改写。选B。
CD-RW：RW=ReWritable可重写。可以反复擦除、反复写入几百次。
记忆：R=一次，RW=多次。

【第30题】答案：D（超媒体采用线性结构组织信息）
题目：以下关于超媒体的叙述中，____是不正确的。
详细解析：
找"错误"叙述。
超媒体 = 超文本 + 多媒体。最大特点：信息之间靠"链接"连接成"网状结构"，你可以点链接随意跳转（就像网页，点一个词跳到另一个页面），这是"非线性"的！
D说"线性结构"（像读小说必须从第一页顺序读到最后一页）——这恰恰说反了，D错误，选D。
A对：超媒体可含图、声、视频；B对：信息可分布存储在多台机器（网页就是这样）；C对：很多软件的"帮助"系统就是超媒体做的。

【第31题】答案：D（FLC文件）
题目：下列文件中，____是动画文件。
详细解析：
文件类型要靠扩展名认人：

MAV（其实是WAV的干扰写法）：音频文件。WAV=波形声音文件。

【第32题】答案：A（存储程序和程序控制）
题目：目前使用的微机是基于____原理进行工作的。
详细解析：
现代计算机都遵循"冯·诺依曼体系结构"，其核心思想两条：
    ① 存储程序：程序和数据事先存进存储器里；
    ② 程序控制：计算机自动按程序逐条执行指令，无需人工干预。
合称"存储程序和程序控制"原理（也叫冯·诺依曼原理），选A。
人工智能、数字控制、集成电路都不是计算机的基本工作原理。

【第33题】答案：A（Internet）
题目：全球最大的计算机网络是____。
详细解析：
Internet（因特网/互联网）：把全世界亿万台计算机连在一起的、全球最大的网络，选A。

NSFNET：美国国家科学基金网，曾是骨干网。
VLAN：虚拟局域网，是局域网里的一种技术划分，不是全球网。

【第34题】答案：A（每个表都必须指定主键）

【第35题】答案：A（网卡物理地址）
题目：MAC地址就是____。
详细解析：
MAC地址 = Media Access Control = 介质访问控制地址。
它是出厂时"固化"在网卡芯片里的唯一编号（48位二进制，写成12位十六进制，如 00-1A-2B-3C-4D-5E），全球唯一、不可更改（可软件伪装），所以叫"物理地址"，选A。
排雷：IP地址是"逻辑地址"，可以手动设置修改，由网络分配，跟物理地址是两码事（选项D错）。

【第36题】答案：A（GIF）
题目：下列文件扩展名中，____是常用的图像文件格式。
详细解析：
扩展名认类型：
GIF：图像格式（支持动画、透明背景，表情包多为GIF），是图像格式，选A。
WAV：声音（波形音频）。
MPG：视频（MPEG视频）。
MID：声音（电子音乐MIDI）。
后三个全是"声音/视频"，只有GIF是图像。

【第37题】答案：C（E-mail）
题目：电子邮件的英文名称是____。
详细解析：

WWW/Web=网页，E-mail=邮件，FTP=传文件。

【第38题】答案：B（254）
题目：二进制数(11111110)2 转换为十进制数是____。
详细解析：
二进制转十进制：每位数字乘以它的"位权"再相加。从右往左位权依次是 1、2、4、8、16、32、64、128。
    1 1 1 1 1 1 1 0
  128 64 32 16 8 4 2 1
第8位到第2位都是1，最右位是0：
    128+64+32+16+8+4+2+0 = 254，选B。
速算法：11111111（8个1）=255，末位变成0就减1：255-1=254。
排雷：253（=255-2）是让粗心的人选的；255是全1；256超了。

【第39题】答案：A（进程管理）
题目：操作系统主要有五种功能：____、存储管理、文件管理、设备管理和作业管理。
详细解析：
操作系统五大功能标准表述：
    处理机管理（进程管理）、存储管理、文件管理、设备管理、作业管理
空缺处就是"进程管理"（也叫处理机管理，负责调度CPU给各个程序用），选A。
"数据管理""目录管理""资源管理"都不是五大功能里的标准名称。

【第40题】答案：D（大规模和超大规模集成电路）
题目：当前使用的Pentium微机，其主要元器件是____。
详细解析：
Pentium（奔腾）是Intel的CPU，CPU里集成了几百万、上亿个晶体管，属于"大规模和超大规模集成电路"，选D。
代代对应：电子管→第一代；晶体管→第二代；中小规模集成电路→第三代；大规模、超大规模集成电路→第四代（现在的微机）。这题和第18题是同一个知识点的两种考法。

第2小题：在"非税收入"表 C4:C10 用公式计算非税收入（=右边各项之和）
────────────────────────────────────────
（"非税收入"表列的排列：B地区、C非税收入、D专项收入、E行政事业性收费收入、F罚没收入、G国有资本经营收入、H国有资源(资产)有偿使用收入、I其他收入。"右边各项"就是 D 到 I 列。）

④ 再点 C4，把鼠标移到单元格右下角的小方块（叫"填充柄"），鼠标变成实心黑十字时，按住左键往下拖到 C10 松手（或者直接双击填充柄，自动填满）。

第4小题："一般预算收入"表 B4:B10 引用两张表数据计算（保留2位小数）
